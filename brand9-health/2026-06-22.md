## Root Cause: CDN Block (`host_not_allowed`)

The response header `x-deny-reason: host_not_allowed` indicates the CDN (likely Cloudflare) is rejecting requests where the Host does not match an allowed domain in the zone configuration. Possible causes:

1. **Cloudflare Bot Fight Mode** blocking datacenter/cloud-provider IPs — most likely, as real-user browser traffic is unaffected.
2. **Cloudflare Access** (Zero Trust) restricting programmatic access.
3. **Misconfigured WAF rule** inadvertently blocking monitoring ranges.

**Recommendation:** Add the monitoring runner's egress IP range to the Cloudflare allowlist, or configure an authenticated bypass token for health-check requests.
