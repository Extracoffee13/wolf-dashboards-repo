## Root Cause: WAF Bot-Block (Critical Audit Limitation)

**All WebFetch requests returned HTTP 403 Forbidden.** The site is running a Web Application Firewall (likely Wordfence, Cloudflare, or equivalent) configured to block non-browser user agents. This is a security best practice, but it means:

- Automated health checks using standard HTTP clients cannot inspect HTML, meta tags, embeds, or prices.
- Checks 1–5 are partially or fully unverifiable in this audit pass.
- **Googlebot is NOT blocked** (confirmed: all pages appear in Google index with rich snippets).
- Real human visitors are NOT blocked.

**Recommendation:** To enable reliable automated health monitoring, allowlist the monitoring agent's IP or user-agent in the WAF, or use a browser-rendered check tool (Playwright, Puppeteer) that passes bot-detection.
