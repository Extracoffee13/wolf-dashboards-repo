## Root Cause

The site's WAF (consistent 403 on all paths including `/robots.txt`) is blocking all requests from cloud datacenter IPs. The site itself is **likely healthy** — all key pages are indexed by Google with correct titles and URLs — but no live verification is possible from this environment.

## Recommendations

1. **Immediate:** Configure a browser-based uptime monitor (UptimeRobot with Chrome agent, or Pingdom real-browser check) to handle the WAF-protected site.
2. **Near-term:** If cloud-agent monitoring is desired, add a Cloudflare Firewall Rule exception for the monitoring agent's static IP, or use Cloudflare's own Analytics dashboard for uptime data.
3. **Standing:** Run manual spot-checks from a browser once per week to verify motion film embed, tile nav, and Yoast SEO fields until automated monitoring is unblocked.
