## Root Cause: 403 on All URLs

Every WebFetch request was rejected with HTTP 403. This is consistent with:

1. **Cloudflare Bot Management / WAF** — aggressively blocking non-browser User-Agents
2. **Wordfence or similar WordPress security plugin** — denying automated monitor IPs
3. **Possible misconfiguration** — a security rule inadvertently blocking all bots

**This is NOT a confirmed site outage.** Google continues to index the site with functional-looking content. However, this monitoring infrastructure is completely blind to the site as long as the 403 persists.

**Recommended action:** Whitelist the monitoring tool's IP range or User-Agent in Cloudflare/Wordfence settings, or switch to a monitoring service that uses browser-based (headless Chrome) checks.
