## Monitoring Environment Note

All direct HTTP checks (WebFetch, curl) returned `HTTP 403 – Host not in allowlist` from the Cloudflare WAF layer. The monitoring infrastructure origin is blocked. To restore functional automated health checks, either:
- Whitelist the monitoring server IP in Cloudflare → Security → WAF → IP Access Rules, or
- Switch to a headless-browser agent (Puppeteer/Playwright) that presents a valid browser fingerprint.

---

## Recommended Actions

1. **Investigate Motion Films page** — Confirm the URL slug, check Yoast SEO visibility setting (Site Settings → Reading → or per-post Yoast panel → "Allow search engines to show this post"), and verify the page is published (not draft).
2. **Whitelist monitor IP in Cloudflare** — Without this, no automated health check can retrieve live page content.
3. **Verify OG image** in a browser dev-tools Network panel or via Facebook Sharing Debugger.
4. **Review content cadence** — Last indexed post was ~6 weeks ago; assess whether this aligns with the editorial calendar.
