## Architecture note (flagged for whoever reviews this)

Per this repo's `b9-site-deploy` knowledge, brand9signs.com was rebuilt as a **static HTML site on
DreamHost** and is explicitly **not WordPress** anymore — Yoast SEO is a WordPress plugin and
would not be live-generating meta tags on a static build. If Yoast fields are present at all,
they'd be meta tags frozen into the static HTML at the migration/export step, not something a
current Yoast install is actively serving. Any future version of this check should confirm
against the live rendered `<head>` (not assume a WP admin/Yoast panel exists) and should get an
explicit answer on whether product/price pages are still commerce-enabled post-migration.
