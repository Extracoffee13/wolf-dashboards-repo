## Root Cause Analysis

The **HTTP 403** responses across all pages are the dominant finding. Possible causes in order of likelihood:

1. **Cloudflare "Under Attack Mode" or Bot Fight Mode** — Site owner may have enabled aggressive bot protection, blocking all non-browser user-agents. This would affect real users only if they fail a JS challenge; bots get 403 immediately.
2. **IP range blocking** — The cloud container's datacenter IP (likely AWS/GCP) may be on a deny list.
3. **Geo-restriction** — Unlikely given SERP visibility, but possible for non-US regions.
4. **Server misconfiguration** — Least likely given pages are still indexed; a true 403 to all would eventually cause de-indexing.

**Recommended action:** Verify from a residential/browser connection. If the site loads normally, configure the monitoring tool with a browser-like User-Agent or use a residential proxy. If the site also 403s in a browser, escalate immediately to the hosting provider.
