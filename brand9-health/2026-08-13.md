   deployed by Hermes. It is **not WordPress** — there is no WooCommerce product catalog, no
   `/product-category/marketing-branding/` page, no Yoast SEO, and no "Motion Films product page."

   `/sign-company-orange-park-fl/`, `/jacksonville-sign-company/`) confirmed via `WebSearch`. So
   items 2, 3, and 4 of this check's spec (category tile/product-card layout, product page price
   checks, Yoast focus keyphrase/meta description/SEO title) describe a WordPress+WooCommerce
   storefront that does not exist on the live site as currently documented. Either the check spec is
   stale (written for a pre-rebuild version of the site) or it targets a different property than
   brand9signs.com's current build — this needs confirming with Bobby/AP before the spec is trusted
   again.

3. Separately, even with egress open, this repo's own docs warn that a plain cloud/Hermes `curl` or
   fetch against brand9signs.com is **lied to by an sgcaptcha bot-shield** — it returns a CAPTCHA
   redirect page (HTTP 202, `<meta http-equiv="refresh">` to `/.well-known/sgcaptcha/`), not the real
   page. Reliable verification requires an authenticated browser session (Claude-in-Chrome / Hermes
   Chrome) holding the sgcaptcha cookie — not available in this session.
