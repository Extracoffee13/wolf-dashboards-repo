## Root Cause: 403 WAF Block

All 12+ fetch attempts across every URL on `brand9signs.com` returned **HTTP 403 Forbidden**. This pattern is consistent with:
- **Cloudflare Bot Fight Mode** or **Super Bot Fight Mode** blocking headless-browser / server-IP traffic
- **Wordfence** rate-limiting or IP-based block on non-browser User-Agent strings
- A Hosting-level firewall (common on WP Engine, SiteGround, Kinsta)

**Impact:**
- Automated health monitoring is completely blind to page-level content.
- Yoast SEO drift, broken embeds, and missing images cannot be caught programmatically.
- Google Crawler appears unaffected (site is indexed), so SEO crawl access is likely whitelisted separately.

**Recommended Fix:**
1. Identify the blocking layer (Cloudflare dashboard → Security → WAF → Events, or Wordfence → Live Traffic).
2. Whitelist the health-monitoring agent's IP or User-Agent in the WAF ruleset.
3. If Cloudflare Bot Fight Mode is enabled, downgrade to Super Bot Fight Mode and add a bypass rule for the monitoring IP.
