## Root Issue: WAF Blocking Automated Monitoring

**All 10 WebFetch probes returned HTTP 403.** The WAF is treating the health-check user-agent as a bot. This is the primary operational blocker for automated health monitoring. Options to resolve:

1. **Whitelist the monitoring IP/UA** in Cloudflare or the hosting WAF rules.
2. **Use Playwright/Puppeteer** with a real browser UA for automated checks.
3. **Use the WordPress REST API** (`/wp-json/wp/v2/`) with an application password for content integrity checks — REST API may have separate WAF rules.
4. **Use an uptime service** (UptimeRobot, Better Uptime) that Cloudflare already allows through.
