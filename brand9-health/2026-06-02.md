## Executive Summary

The site is indexable by Google and all key page URLs resolve in search results, but **every direct HTTP fetch returned 403 Forbidden** — the WAF/bot-protection layer (likely Cloudflare or Wordfence) is blocking automated user-agents entirely. This prevents verification of rendered content, embeds, Yoast SEO meta output, and OG images. Additionally, the **Motion Films product page has no presence in Google's search index**, which is either a missing page or a `noindex` directive drift.

## WAF/Bot-Blocking — Critical Infrastructure Note

**All 8 WebFetch requests** across 5 different page URLs returned `HTTP 403 Forbidden`. This is consistent with Cloudflare Bot Fight Mode, Wordfence Premium, or a custom `.htaccess` rule blocking non-browser user-agents. Key implications:

- Googlebot receives **special bypass** (site is indexed) — so SEO crawling is unaffected
- Social media link previewers (Facebook, LinkedIn, Slack unfurl) may also be blocked, impacting OG image rendering in shares
- Monitoring tools (UptimeRobot, Pingdom, this health check script) are all blocked, creating a **blind spot** for automated uptime verification
- **Recommendation:** Whitelist the monitoring tool user-agent in WAF rules, or use a headless-browser-based checker (Playwright/Puppeteer) that mimics a real browser.
