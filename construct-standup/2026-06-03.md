## 5. One Non-Obvious Thing I Noticed

**The git repo is the backend.** There is no separate database, no API server, no cron-job dashboard polling an endpoint. WOLF commits live JSON to GitHub every 5 minutes, and the HTML dashboards (`WOLF_Command_Center.html`, `Agent_Wolf_Construct.html`) read that committed file as their data source. Git history IS the trading ledger. This makes the system zero-infra and fully auditable — every state change is a signed, timestamped commit — but it also means the dashboard's "live" latency is bounded by commit frequency (currently 5 min) and GitHub Pages cache TTL. The elegance is real, but the implication is that any agent-to-agent communication or cross-agent coordination that relies on this repo will also inherit the 5-minute write cycle as its bus speed. If inter-agent coordination ever needs to happen faster than that, the architecture will need a lower-latency channel.
