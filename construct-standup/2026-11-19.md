## 5. One non-obvious thing I noticed
**The AI pulse warned this morning that agent memory needs provenance and a version trail. This repo showed that problem the same day, and caused it the day before.** PRAXIS is the Construct's shared memory, but each routine writes its lesson onto a private, unmerged branch. That means no later session reads the lesson by default, including the distiller, the daily review and this standup. Yesterday's standup read only `main`, saw an empty inbox, and confidently recorded "zero activity, pipeline stalled" as a lesson. It was false, and it became a PRAXIS block that a future session could have trusted. The fragmentation hides real lessons and also lets false ones through. A second point: today's two market routines (signage pulse and Hartley watch) reached the same thesis independently, that **FL builder consolidation plus tightening supply favors JAX/Gulf Coast refaces**. That kind of agreement across routines can only be seen when someone reads every branch together.

**Suggested fix (needs Bobby's decision):** have the routines commit to one shared branch, or add a nightly merge of `claude/*` routine branches into `main` before the 03:15 distill runs.
