## Candidates (score ≥ 3)

### 1. MCP Specification 2026-07-28 (stateless core, Extensions framework, Apps/Tasks) — Score 5
- **Source:** https://blog.modelcontextprotocol.io/posts/2026-07-28/ (also: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude)
- **Pitch:** The protocol drops the stateful `initialize`/session-ID handshake in favor of a stateless request/response core, adds a versioned Extensions framework (MCP Apps for embedded UI, redesigned Tasks for long-running work), and hardens OAuth/OIDC — Claude already supports it, and every MCP server we connect (GitHub, Canva, Slack, Higgsfield, Gmail, Drive) inherits the change.
- **Suggested owner:** Architect

### 2. GitHub MCP Server — stateless spec support shipped early — Score 4
- **Source:** https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/
- **Pitch:** GitHub's own MCP server (the one this repo's `github` connector runs on) shipped support for the new stateless spec five days ahead of the official release, dropping Redis-backed sessions — a direct, drop-in reliability/latency upgrade for the exact tool AP/Architect use to work this repo.
- **Suggested owner:** Architect

### 3. agentic-flow (ruvnet) — cost-optimal model router + autonomous code repair for Claude Code/Agent SDK — Score 4
- **Source:** https://github.com/ruvnet/agentic-flow
- **Pitch:** A runtime that sits in front of Claude Code/Agent SDK, routes each query to the cheapest adequate model (Anthropic, OpenRouter, Gemini, local ONNX) claiming ~60% cost savings, and includes an "AgentBooster" auto-repair mode for code-edit tasks at near-zero marginal cost — worth a pilot given how many agents in the fleet run Claude Code sessions daily.
- **Suggested owner:** Architect

### 4. real-estate-mcp (agentic-ops) — MCP server for property search, CMA valuation, mortgage math, investment analysis — Score 4
- **Source:** https://github.com/agentic-ops/real-estate-mcp
- **Pitch:** V2.0 MCP server giving an agent property search/filtering, comparable-market-analysis valuation, mortgage amortization/affordability/refi comparisons, and investment-return analysis, with optional live data (Census, Walk Score, FEMA, FRED, RentCast, Zillow) gated behind cost controls — a plausible weekly tool for Hartley Capital real-estate work.
- **Suggested owner:** Equity

### 5. comfyui-mcp (artokun) — local-first, agent-native control plane for ComfyUI — Score 3
- **Source:** https://github.com/artokun/comfyui-mcp
- **Pitch:** MCP server + Claude Code plugin exposing 108 tools / 29 image-gen skills (Flux, WAN, Ideogram4, Krea2, Qwen) to author workflows and edit a live ComfyUI graph in natural language, running on your own Claude subscription with no extra API cost — niche but a real fit if Vector ever needs local/self-hosted image-gen alongside Higgsfield.
- **Suggested owner:** Vector
