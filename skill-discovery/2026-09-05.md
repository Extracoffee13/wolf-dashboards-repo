- Source: https://pypi.org/project/fastmcp/
- Pitch: The de facto Pythonic framework for building MCP servers/clients fast (schema generation, validation, docs handled automatically); latest release confirmed Sep 5, 2026, and it reportedly powers ~70% of MCP servers in the wild — the tool to reach for whenever the Construct needs a bespoke internal MCP server.
- Suggested owner: **Forge** (build/dev agent)

### 3. MCP Registry (official preview) — score 3
- Source: https://blog.modelcontextprotocol.io/posts/mcp-roadmap/
- Pitch: An open catalog/API from the Model Context Protocol project for indexing and discovering MCP servers, intended as the single source of truth across public/private sub-registries — could replace ad-hoc directory scraping in future discovery sweeps like this one.
- Suggested owner: **Architect** (infrastructure/tooling agent)

### 4. Redfin-backed Real Estate MCP Server (Apify / nexgendata) — score 3
- Source: https://apify.com/nexgendata/redfin-mcp-server
- Pitch: Gives an agent live US residential property search and full listing detail sourced from Redfin as callable MCP tools — useful for market-comp pulls without a custom scraper.
- Suggested owner: **Equity** (investment/finance agent)

### 5. Claude Cowork "Record a Skill" — score 4

- Pitch: Lets anyone demonstrate a workflow on screen, narrate the decisions/exceptions, and have Claude convert the recording into a reusable Skill — a no-code path for the team to keep growing the Construct's own skill library without engineering time.
