### 1. Claude Managed Agents — Multiagent Sessions & Outcomes (Public Beta)

**Source:** https://platform.claude.com/docs/en/release-notes/overview  
**Score: 5**  
**Primary Owner: WOLF / Architect**

Anthropic's Managed Agents platform now supports structured multiagent sessions with an Outcomes tracking layer in public beta — agents can spawn sub-agents, pass state, and record a typed result object per session. ### 2. Claude Managed Agents — Memory (Public Beta)

**Source:** https://platform.claude.com/docs/en/release-notes/overview  
**Score: 5**  
**Primary Owner: Oracle / WOLF**

Persistent cross-session memory is now in public beta for Claude Managed Agents. Agents can read and write a structured memory store that survives beyond individual session boundaries, enabling recall of past decisions, client preferences, and project context without external vector DBs. Oracle's knowledge-retrieval workflows and WOLF's long-horizon coordination tasks are the immediate beneficiaries — this replaces the pattern of manually re-injecting prior context at session start.

### 4. Claude Code v2.1.166 — Fallback Models + Thinking Token Controls

**Source:** https://github.com/anthropics/claude-code/releases  
**Published:** June 6, 2026 (00:55 UTC)  
**Score: 4**  
**Primary Owner: Forge**

**Source:** https://github.com/zouyingcao/agentskills-mcp  
**Score: 3**
