### 2. CVE MCP Server
**Source:** https://github.com/mukul975/cve-mcp-server
**Published:** Active May 2026 (widely covered this week)
**Score:** 4
**Suggested owner:** Sentinel

Open-source FastMCP server giving Claude 27 security intelligence tools across 21 APIs in a single natural-language interface: NVD CVE lookup, EPSS exploitation probability, CISA KEV status, MITRE ATT&CK mapping, Shodan host exposure scanning, VirusTotal malware association, bulk CVE batch lookup, and more. Pure outbound HTTPS, no inbound ports, no telemetry, no API key logging. Drop-in install for Claude Desktop and Claude Code.

**Why it scores 4:** Sentinel would use this weekly for vulnerability triage across The Construct's infrastructure — replaces multi-tab manual lookups with a single Claude conversation.

### 5. skill-to-mcp (BioContextAI)
**Source:** https://pypi.org/project/skill-to-mcp/
**Version:** 0.2.1 · Published: Feb 27, 2026
**Score:** 3
**Suggested owner:** Architect

`pip install skill-to-mcp` — auto-discovers Claude Skills from a local directory, parses YAML frontmatter, and exposes them as MCP resources via three tools: `get_available_skills`, `get_skill_details`, `get_skill_related_file`. Built-in path validation prevents directory traversal. Domain-agnostic despite its biomedical origin.

**Why it scores 3:** Clean bridge for making The Construct's own skill library MCP-accessible without rewriting each skill — Architect could wire this into the skills depot in an afternoon.
