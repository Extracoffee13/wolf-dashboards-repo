## Ecosystem Observation

The clearest trend this cycle: **the Anthropic platform is converging toward a full managed-agent PaaS**. Scheduled deployments, self-hosted sandboxes, vault credential injection, MCP tunnels, and webhook event streaming all shipped within a 6-week window (May–June 2026). The ecosystem is bifurcating into (a) Claude-native managed agents with deep platform integration and (b) MCP-bridge adapters that make those capabilities portable to other runtimes. The Construct sits at the intersection — the highest-leverage moves are to go deeper on Anthropic's managed layer for production agents (WOLF, AP, Equity) while using adapters like `agentskills-mcp` to keep the skill library runtime-agnostic.
