### 1. Claude Managed Agents — "Dreaming" Memory Consolidation
**Source:** [Anthropic VentureBeat coverage](https://venturebeat.com/technology/anthropic-introduces-dreaming-a-system-that-lets-ai-agents-learn-from-their-own-mistakes) · [Slashdot](https://slashdot.org/story/26/05/06/1714217/claude-managed-agents-can-engage-in-a-dreaming-process-to-preserve-memories)  
**Score:** 5 — drop-in upgrade for existing agent skills  
**Suggested Owner:** WOLF / AP  

**Pitch:** A background process that reviews up to 100 past agent sessions, merges duplicate memories, surfaces recurring mistakes as structured "playbooks," and rewrites the agent's memory store so each subsequent run is smarter — no model retraining required. Early adopter Harvey (legal AI) saw task-completion rates increase ~6× after enabling it. Now in research preview under Claude Managed Agents.

**Why it matters to The Construct:** Every scheduled WOLF agent (daily reviews, inbox scans, brief generation) currently starts each session cold. Dreaming lets them accumulate institutional knowledge across runs — a direct force-multiplier for AP, Forge, and any agent doing repetitive research or reconciliation work.

### 5. skill-to-mcp (PyPI)
**Source:** [PyPI](https://pypi.org/project/skill-to-mcp/) · [Docs](https://skill-to-mcp.readthedocs.io/en/latest/)  
**Score:** 3 — niche but useful  
**Suggested Owner:** Keystone / AP  

**Pitch:** A Python library (v0.2.1, Feb 2026) by BioContextAI that auto-discovers Claude Skills in a configured directory and exposes them as MCP server resources via three standard tools: `get_available_skills`, `get_skill_details`, and `get_skill_related_file` — making any skill collection accessible to any MCP-compatible LLM client.

**Why it matters to The Construct:** As The Construct's skill library grows, skill-to-mcp provides a lightweight registry layer that lets any agent discover and invoke skills without hardcoded wiring. AP could use this to give WOLF a dynamic skill manifest rather than maintaining a static list.
