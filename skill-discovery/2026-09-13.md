# Skill Discovery Sweep — 2026-09-13

`agent-skills`, `mcp-server`), npm (`mcp-server`, `anthropic-skill`), PyPI (`claude-skill`, `mcp`),

release date).

## Candidates (score ≥ 3)

### 1. Claude Skills MCP Server — score 4
- **Source**: https://github.com/K-Dense-AI/claude-skills-mcp
- **Pitch**: Vector/semantic search over installed Agent Skills so an agent finds the right skill by
  meaning instead of scanning a flat list — the same progressive-disclosure pattern Anthropic
  describes for Agent Skills, exposed as an MCP server.
- **Suggested owner**: Architect
- **Why it matters**: This is a drop-in upgrade for the discovery sweep this very task runs — instead
  of manual keyword searches across directories, point this MCP server at our own skill roster (60+
  skills already loaded) and at external catalogs for semantic matching.

### 2. SkillFlow MCP Server — score 4
- **Source**: https://glama.ai/mcp/servers/rafsilva85/skillflow-mcp-server
- **Pitch**: Connects an agent to the SkillFlow marketplace to search, discover, and install agent
  skills directly from Claude, Cursor, Copilot, or Gemini CLI without leaving the session.
- **Suggested owner**: AP
- **Why it matters**: New capability the ecosystem would use weekly — turns "search 4 directories by
  hand" (this task's own method) into a single queryable tool, cutting sweep time.

### 3. Google Search Console + GA4 MCP Server (GenieSeo / nrvmodi build) — score 5
- **Source**: https://github.com/nrvmodi/google-search-console-mcp-server
- **Pitch**: 28 tools (21 Search Console + 7 GA4) exposed as one MCP endpoint — property inspection,
  indexing requests, and analytics pulls without hand-rolled OAuth/service-account plumbing.
- **Suggested owner**: Signal
- **Why it matters**: Drop-in upgrade for the existing `gsc-ga-creative-abrasion`,
  `b9-google-api-access-setup`, and `gsc-url-inspection-index-sweep` skills, which currently fight
  Google Cloud project/2FA friction (documented pain in `b9-google-api-access-setup`). Worth a
  spike to see if it can replace the custom service-account wiring outright.

### 4. HouseCanary MCP Server — score 4
- **Source**: HouseCanary (MCP server released ~April 2026; exposes 149 HouseCanary endpoints)
- **Pitch**: Property-level valuations, rental estimates, sales/tax history, flood and hazard data,
  and forecasts, callable directly from an MCP-compatible agent.
- **Suggested owner**: Ledger
- **Why it matters**: Direct hit for Hartley Capital underwriting/due-diligence work — real
  comps and hazard data on tap instead of manual pulls. Flagged even though it predates this
  sweep's 24h window because it doesn't appear to be in use anywhere in this repo yet.

### 5. npm-mcp — score 3
- **Source**: https://github.com/mikusnuz/npm-mcp
- **Pitch**: MCP server wrapping 32 npm tools (publish, install, audit, search, security scanning)
  so an agent can manage JS/TS package hygiene without shelling out to raw `npm` commands.
- **Suggested owner**: Forge
- **Why it matters**: Niche but useful — mainly relevant if/when Forge is doing JS/TS build or
  dependency-audit work; lower priority than the above.
