### 2. skill-to-mcp v0.2.1
**Score: 4 — new capability the team would use weekly**

| Field | Detail |
|---|---|
| Source | https://pypi.org/project/skill-to-mcp/ |
| Published | 2026-02-27 (latest stable; actively maintained) |
| Primary Owner | **Forge** |

A Python library by Malte Kuehl that reads any directory of Claude-format SKILL.md files and auto-generates a live MCP server exposing three tools: list skills, get skill detail, and read skill files. Includes path-traversal protection. One-command install; no code required beyond pointing it at a skills directory.

**Why it matters:** The Construct maintains a growing library of custom agent skills. Today those skills are Claude-native only. skill-to-mcp lets Forge expose the entire skill library to Cursor, Copilot, or any other MCP-compatible coding agent without rewriting a single skill — skills become infrastructure, not Claude-specific scripts.
