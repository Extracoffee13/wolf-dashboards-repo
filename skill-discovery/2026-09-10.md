# Skill & MCP Discovery Sweep — 2026-09-10

## Method & caveat

Sweep covered mcp.directory/modelcontextprotocol.io, GitHub (topics `claude-skill`, `mcp-server`, `anthropic-skill`), npm, PyPI, and anthropic.com/news + claude.com/blog, via web search and direct fetch where reachable.

Two access limits narrowed this cycle: GitHub's own search/topics pages returned HTTP 429 (rate-limited, retry-after 1hr) so topic listings couldn't be sorted by creation date directly, and `anthropic.com` / `claude.com` are blocked by this session's egress proxy (fetched via search-index summaries and `platform.claude.com/docs/release-notes` instead, which *is* reachable). Cross-checking the official release notes directly confirmed **no new Anthropic platform entries landed in the strict Sept 8–10 window** — the most recent is the `ant apply` CLI command from Sept 3. Candidates below are therefore the most relevant *recently-active* items surfaced this cycle, not all confirmed to have shipped inside the last 24 hours; treat the "score ≥3" list as a rolling watchlist rather than a same-day-only feed.

## Candidates (score ≥ 3)

### 1. `ant apply` CLI command — score 4
- Source: https://platform.claude.com/docs/en/release-notes/overview (Sept 3, 2026 entry)
- Pitch: One CLI command that creates/updates agents, environments, skills, memory stores, and deployments straight from repo files — infrastructure-as-code for exactly the kind of named-agent fleet The Construct runs.
- Suggested owner: **Architect**

### 2. cre-agent-skills v1.6.0 — score 4
- Source: https://github.com/ahacker-1/cre-agent-skills
- Pitch: 90+ Apache-2.0 commercial-real-estate skills (underwriting, due diligence, financing, brokerage, legal, closing) plus new Retail, Lender/Credit, and Development & Construction packs — direct overlap with Hartley Capital's CRE workflows and the site/permit work ANS-adjacent agents already do.
- Suggested owner: **Ledger**

### 3. finance-skills (himself65) — score 3
- Source: https://github.com/himself65/finance-skills
- Pitch: Agent-Skills-standard collection for stock/earnings/ETF/options analysis plus VC-style startup evaluation frameworks — useful for one-off diligence questions, not a weekly driver.
- Suggested owner: **Ledger**

### 4. skill-mcp / skills-mcp family (skill-mcp, skill-mcp-server, skills-mcp) — score 3
- Source: https://pypi.org/project/skill-mcp/, https://pypi.org/project/skill-mcp-server/
- Pitch: MCP servers that let an agent dynamically discover/install/load skill folders at runtime from a shared registry — plumbing that could let The Construct's agents pull new skills without a redeploy, but still early/fragmented across competing packages.
- Suggested owner: **Architect**

### 5. Skills API — beta headers dropped (GA) — score 3
- Source: https://platform.claude.com/docs/en/release-notes/overview (Aug 27, 2026 entry)
- Pitch: `skills-2025-10-02` and the Files API no longer require beta headers, meaning Skills API calls are now stable/production-grade for any agent built directly on the Messages API.
- Suggested owner: **AP**
