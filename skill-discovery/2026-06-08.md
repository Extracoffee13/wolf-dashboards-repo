## Signal Summary

The clearest theme this cycle: **the skill/MCP boundary is collapsing**. `skill-to-mcp` and `agentskills-mcp` both treat Skills as first-class MCP artifacts. Anthropic's own SDK formalises in-process MCP servers. The practical implication for The Construct is that the authoring-to-deployment pipeline for new capabilities is now a single pip/npm install rather than custom wiring.
