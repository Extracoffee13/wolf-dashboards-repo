## Candidates (score ≥ 3, max 5)

### 1. MemClaw — score 5
- **Source:** https://github.com/caura-ai/caura-memclaw (plugin v2.15.1, released 2026-07-20)
- **Pitch:** Governed, shared, self-improving memory for multi-agent fleets — trust tiers, visibility scopes, contradiction detection, and audit trails for agents recalling what other agents learned.
- **Why it matters:** This is functionally what praxis-inbox.md and the WOLF live-data append pattern are hand-rolling today, but productized with governance and multi-tenant isolation — a plausible drop-in upgrade to how the whole Construct shares institutional memory across agents.
- **Suggested owner:** Architect

### 2. deja-vu — score 4
- **Source:** https://github.com/vshulcz/deja-vu (v0.14.1, released 2026-07-20)
- **Pitch:** Local-first MCP server that indexes past coding-agent session logs (Claude Code, Codex, Cursor) so an agent can retroactively search and recall how a problem was solved before, instead of re-solving it.
- **Why it matters:** Directly useful for any agent doing repeat engineering work across sessions in this repo.
- **Suggested owner:** Forge

### 3. CoDesign (IMG.LY) — score 4
- **Source:** https://github.com/imgly/codesign
- **Pitch:** MCP server wrapping IMG.LY's CE.SDK engine — lets an agent generate, edit, resize, and localize fully-editable designs and export print-ready, CMYK-correct PDFs straight from conversation.
- **Why it matters:** A weekly-use capability for anything moving from social graphic to print-ready collateral for Brand 9 Signs.
- **Suggested owner:** Vector

### 4. jDocMunch-MCP — score 3
- **Source:** https://github.com/jgravelle/jdocmunch-mcp (v1.109.0, released 2026-07-21)
- **Pitch:** Indexes documentation by heading hierarchy and serves single sections via stable IDs instead of forcing full-file reads — claims ~100k → ~2k token reduction for doc-heavy lookups (Markdown/RST/AsciiDoc/OpenAPI/notebooks).
- **Why it matters:** Niche but cheap win anywhere an agent burns context reading long third-party docs (API references, vendor integration guides).
- **Suggested owner:** Architect

### 5. Blackveil DNS (bv-mcp) — score 3
- **Source:** https://github.com/MadaBurns/bv-mcp (v3.32.0, released 2026-07-21)
- **Pitch:** Zero-install MCP endpoint exposing 80 tools for DNS/email security auditing — SPF/DMARC/DKIM, DNSSEC, BIMI/lookalike-domain detection, compliance mapping (NIST/PCI/SOC 2), with automated remediation record generation.
- **Why it matters:** Niche but directly actionable for auditing Brand 9 Signs' and client domains' email-spoofing exposure.
- **Suggested owner:** Sentinel
