### 1. Suganthan's GSC MCP Server — score 5
- **Source:** https://github.com/Suganthan-Mohanadasan/Suganthans-GSC-MCP (npm: `suganthan-gsc-mcp`, published 2026-08-18)
- **Pitch:** A Google Search Console MCP server exposing 20 ready-made SEO analysis tools (quick wins, traffic drops, content decay, keyword cannibalisation, CTR opportunities, multi-site dashboards) with OAuth *and* service-account auth support.
- **Why it scores high:** This is close to a drop-in replacement for the manual GSC table-scrape at the core of `gsc-ga-creative-abrasion` and the painful auth dance documented in `b9-google-api-access-setup` (2-Step Verification block, quota-project routing). If the service-account path works against the `brand9-gbp` project, it collapses several custom scripts into direct MCP tool calls.
- **Suggested owner:** Signal

- **Source:** https://github.com/Baxter-Inc/seoagent-npm (npm: `@seoagent-official/seoagent`, published 2026-08-19)
- **Pitch:** A "persistent AI SEO agent" skill/CLI for Claude Code covering audits, keyword strategy, content briefs, article drafts, internal linking, and schema markup — with explicit AEO/GEO (answer-engine-optimization / generative-engine-optimization) framing in its own keywords.

### 3. `discernment-nudge` (official Anthropic skill) — score 4
- **Source:** https://github.com/anthropics/skills/tree/main/skills/discernment-nudge (merged 2026-08-17, PR #1553)
- **Pitch:** Appends 2–3 targeted follow-up questions after any substantive recommendation, estimate, or drafted artifact, modeling fact-check / reasoning-check / missing-context habits before the user acts on it.
- **Why it matters:** Official, zero-setup, and generically useful across every advisory agent in the Construct (finance calls from WOLF/Sentinel, copy claims from Cornerstone/Signal, build recommendations from Architect) — a cheap weekly-use addition, not a niche tool.
- **Suggested owner:** Sentinel
