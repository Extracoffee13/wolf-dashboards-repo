## Candidates (score ≥ 3)

### 1. comfyui-mcp — score 4
- **Source:** https://github.com/artokun/comfyui-mcp (npm last publish 2026-07-10)
- **Pitch:** Local-first, agent-native control plane for ComfyUI — 108 tools and 29 model-specific AI skills (Flux, WAN, Qwen, Ideogram4, Krea2) that let an agent author, edit, and run image/video generation graphs in natural language instead of just forwarding a prompt.
- **Suggested owner:** Vector
- **Note:** Overlaps with the existing Higgsfield MCP connection but is self-hostable and graph-native rather than API-metered — worth a bake-off if signage mockup volume grows.

### 2. thumbgate (npm package `mcp-memory-gateway`) — score 4
- **Source:** https://github.com/IgorGanapolsky/ThumbGate (npm last publish 2026-07-09)
- **Pitch:** Self-improving agent governance — a thumbs-down on a mistake gets promoted into a permanent Pre-Action Check that blocks the same failure mode across every future session, model, and agent, with confidence weights tuned via Thompson Sampling.
- **Suggested owner:** Architect
- **Note:** Conceptually close to what praxis-inbox.md is already doing by hand (decision/lesson/confidence logging) — this is a candidate to formalize that pattern into enforced pre-action checks rather than passive notes.

### 3. @aifinpay/mcp — score 3
- **Source:** https://github.com/AiFinPay (npm last publish 2026-07-10)
- **Pitch:** Pay-per-call x402 payment rail for autonomous agents on Polygon/Solana — gives an agent a wallet and lets it autonomously pay for any x402-gated API call, non-custodial.
- **Suggested owner:** Ledger
- **Note:** Niche and crypto-rail-specific; useful to track as agent-to-agent commerce infrastructure matures, but on-chain custody/compliance questions need review before any live use.

### 4. mcp-video-analyzer — score 3

- **Pitch:** MCP server that extracts transcripts, key frames, OCR text, and metadata from video — usable for auditing motion-deck/video assets or ingesting competitor video content.
- **Suggested owner:** Spectra
- **Note:** Could feed WOLF dashboard reporting on video-asset performance if that becomes a tracked metric.

### 5. agent-device — score 3

- **Pitch:** Agent-native CLI for driving AI app automation across iOS, Android, and tvOS — lets an agent script and QA mobile/TV app flows directly.
