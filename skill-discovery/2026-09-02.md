**Pitch:** Universal SEO skill for Claude Code — 25 sub-skills + 18 sub-agents covering technical SEO, E-E-A-T, schema markup, GEO/AEO, local SEO, maps intelligence, and PDF/Excel reporting, with optional DataForSEO/Firecrawl extensions (13.7k GitHub stars).

**Suggested owner:** Signal

### 2. GitHub MCP Server v1.10.0 — Score 4
**Source:** https://github.com/github/github-mcp-server (see also https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/)
**Pitch:** Security/reliability release of GitHub's official MCP server — confirmed repo deletion with elicitation, bearer-credential host restrictions, request-limit hardening, and stateless-protocol support ahead of the July 28 2026 MCP spec.
**Why it scores 4:** We drive nearly all PR/CI babysitting through `mcp__github__*` tools today; the hardening (cache isolation, URL-traversal fixes, stateless sessions) is a capability/safety upgrade the team would pick up automatically on next server bump, and is worth deliberately tracking rather than assuming.
**Suggested owner:** Forge

### 3. Local SEO Skills (garrettjsmith/localseoskills + localseoskills.com hosted workspace) — Score 4
**Source:** https://github.com/garrettjsmith/localseoskills ; https://localseoskills.com/
**Pitch:** Open-source Claude local-SEO skill set (38 skills) plus an optional hosted workspace adding persistent per-client briefs, scheduled monitoring, and white-label reports.
**Why it scores 4:** New capability the team would use weekly on Brand 9 Signs and other local-business clients — the "persistent client memory + scheduled monitoring + white-label report" pattern is exactly the manual step we currently improvise per client in the flywheel skills.
**Suggested owner:** Venture

### 4. portfolio-mcp (l4b4r4b4b4/portfolio-mcp) — Score 4
