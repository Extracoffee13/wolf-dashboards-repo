## Candidates (score ≥ 3)

### 1. Pentimento — local ledger + undo for agent actions — Score: 5
- **Source:** https://github.com/RedRio-bit/pentimento
- **Pitch:** A single-file, append-only, content-addressed (SHA-256) log of every action an AI agent takes on a machine, with a declared inverse for undo/compensate/approve per action — ships an MCP server (`pentimento-fs`) for zero-modification integration with Claude Code/Desktop.
- **Why it scores 5:** This is functionally the missing local-execution half of what `praxis-inbox.md` already does at the decision-log level — Pentimento would give per-action undo and tamper-evident hashing underneath it. Drop-in upgrade candidate for how The Construct's agents record and can roll back file/system-level actions.
- **Owner:** Ledger

### 2. Archestra v1.3.3 — MCP registry, gateway & guardrails — Score: 4
- **Source:** https://github.com/archestra-ai/archestra
- **Pitch:** Open-source enterprise AI platform (3.9k★, $13.5M funded) shipping a private MCP registry + OAuth gateway, "Dual-LLM / Lethal-Trifecta" guardrails for tool-call validation, and Kubernetes-native agent orchestration — v1.3.3 released 2026-07-07.
- **Why it matters:** The Construct is already running ~18 named agents against a growing MCP tool surface; a self-hosted registry/gateway with per-user OAuth and deterministic guardrails is exactly the control plane that gap analysis would flag next as the agent count grows.
- **Owner:** Atlas

### 3. Agent Skills team library relaunch (Agentman) — Score: 4
- **Source:** https://agentman.ai/blog/agent-skills-relaunch-team-layer-claude-skills
- **Pitch:** Third-party governance layer on top of Claude Agent Skills — Google-Docs-style sharing, use-only access that redacts skill internals while still logging every run, version history 2.0 with visual diff/one-click restore, and workspace-wide access logs; free tier covers 3 seats / 10 published skills.
- **Why it matters:** The Construct has no version history or access log for the skills its agents share today — this is a weekly-use capability once more than a couple of people/agents are editing the same skill set, directly relevant to how `praxis-inbox.md` tracks lessons but doesn't yet track skill provenance.
- **Owner:** Keystone

### 4. x402-tools — paid agent tools with secret scanning & config auditing — Score: 3
- **Source:** https://github.com/fablerlabs/x402-tools
- **Pitch:** Toolkit for agents transacting over the x402 paid-API protocol, bundled with secret scanning and agent-config auditing so an agent's payment credentials/config don't leak.
- **Why it matters:** Niche today, but relevant the moment any Construct agent (Equity/Ledger/Venture) starts paying for third-party data or tool calls autonomously — worth a bench-test rather than immediate adoption.
- **Owner:** Equity

### 5. mcp-textbrowser — token-cheap headless browser for agents — Score: 3
- **Source:** https://github.com/bytesbrains/mcp-textbrowser
- **Pitch:** Text-first headless browser (DOM + OCR) MCP server that sends zero image tokens by default, claimed 5–15x cheaper than screenshot-based browsing for agent web research.
- **Why it matters:** Directly cuts cost for any agent doing repeated web lookups (market scans, competitor research); low integration risk, worth piloting on one research-heavy agent before wider rollout.
- **Owner:** Vector
