## Candidates (score ≥ 3)

### 1. Claude Platform GA: Computer Use, Browser Use, Skills API, Files API — Score 5
- **Source:** Anthropic platform release, Aug 19–20 2026 (via [Enterprise DNA coverage](https://enterprisedna.co/resources/news/anthropic-browser-use-computer-use-skills-api-enterprise-ga-august-2026/), [AI Catchup](https://aicatchup.com/news/claude-platform-computer-browser-skills-files-ga))
- **Pitch:** Computer use, a new browser-use tool (accessibility-tree-aware element/form/tab targeting), the Skills API, and the Files API (5x rate limits, 1TB org storage, file expiration) all moved out of beta simultaneously — this is the exact stack Hermes/computer-use driving and the finance-document workflows (Ledger) already depend on informally.
- **Suggested owner:** Architect (agent infra/tooling — evaluate migrating Hermes computer-use and any file-upload flows onto the GA toolset and its higher rate limits).

### 2. SE Ranking `seo-skills` — Claude Agent Skills for the SE Ranking MCP server — Score 4
- **Source:** [github.com/seranking/seo-skills](https://github.com/seranking/seo-skills)
- **Pitch:** 26 production Claude Skills (incl. `seo-ai-search-share-of-voice`, `seo-geo`, `seo-content-brief`, `seo-schema`, `seo-drift`, `seo-technical-audit`) that turn SE Ranking API data into finished SEO/GEO deliverables — directly overlaps with the B9 visibility/creative-abrasion work.
- **Suggested owner:** Signal (B9 AI-visibility / GEO-AEO signal tracking, complements `mallard-b9-visibility` and `gsc-ga-creative-abrasion`).

### 3. HostTracker MCP server — uptime monitoring via MCP — Score 4
- **Source:** [github.com/HostTracker/mcp](https://github.com/HostTracker/mcp)
- **Pitch:** Exposes instant multi-location HTTP/ping/TCP/DNS checks, monitor CRUD, incident history, maintenance windows, and status pages as MCP tools — a ready-made backend for the site-health auto-repair loop instead of hand-rolled scan scripts.
- **Suggested owner:** Sentinel (site-health monitoring/auto-repair — pairs with `b9-site-health-sentinel`).

### 4. Firecrawl "Keyless" + automatic PII redaction — Score 3
- **Source:** [firecrawl.dev/blog/category/product-updates](https://www.firecrawl.dev/blog/category/product-updates)
- **Pitch:** No-API-key scrape/search (1,000 free credits/mo) lowers friction for one-off research pulls, and a new automatic PII-redaction pass (names, emails, phones, addresses, secrets stripped from scraped content) matters for anything Hartley Capital-adjacent that touches scraped third-party data.
- **Suggested owner:** Cipher (data handling/compliance-sensitive scraping).

### 5. `mcp-gsc` — Google Search Console MCP server — Score 3
- **Source:** [github.com/AminForou/mcp-gsc](https://github.com/AminForou/mcp-gsc) (latest release v0.3.3, July 2026; still the most-referenced GSC MCP surfacing this cycle)
- **Pitch:** 20+ tools across property management, search analytics, URL inspection, and sitemap management for GSC via natural language — a candidate to formalize the ad hoc GSC pulls already done for `gsc-ga-creative-abrasion`.
- **Suggested owner:** Signal.
