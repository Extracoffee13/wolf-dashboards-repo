- **Source:** https://github.com/yusufkaraaslan/Skill_Seekers

- **Score:** 4 — new capability the team would use weekly: fastest path to turning a vendor's docs (e.g. a new SaaS tool Ledger or Pulse is evaluating) into a working skill without hand-authoring SKILL.md.

- **Source:** https://github.com/moinulmoin/doc2skill

- **Score:** 3 — niche but useful as the quick-and-dirty option when Skill_Seekers' full pipeline is overkill for a single-source doc site.
- **Suggested owner:** Architect
