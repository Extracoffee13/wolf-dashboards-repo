## Candidates (score ≥ 3)

### 1. Alpaca official MCP Server — v2.3.1 (Sept 1, 2026) — Score 5
- Source: https://github.com/alpacahq/alpaca-mcp-server
- Pitch: Official, FastMCP/OpenAPI-based MCP server for Alpaca covering account/portfolio state, order management (stocks, options, crypto, multi-leg spreads), and live/historical market data — natural-language trading directly from an MCP client, paper-account-ready out of the box.
- Owner: **WOLF** — this is a near drop-in replacement/upgrade path for WOLF's current custom `alpaca_trader.py` execution script; worth a spike to see if it can absorb the "Execute First Signals" and future ML-confirmation-layer steps on the WOLF roadmap.

### 2. search-console-mcp (GSC + Bing + GA4 + AdSense unified) — v2.1.2 — Score 5
- Source: https://github.com/saurabhsharma2u/search-console-mcp
- Pitch: Single MCP server fusing Google Search Console, Bing Webmaster Tools, GA4, and AdSense into one context window, including a GenAI query-insights tool that flags conversational/AI-engine-driven search traffic.
- Owner: **Signal** — the GenAI query-detection tool overlaps directly with the B9 AI-visibility flywheel (mallard-b9-visibility, gsc-ga-creative-abrasion) and could shortcut the painful service-account/2FA/quota-project setup documented in `b9-google-api-access-setup`; needs a security pass before touching live GSC/GA4 credentials.

### 3. Official Blender MCP Server — v1.0.3 (Sept 11, 2026) — Score 4
- Source: https://www.blender.org/lab/mcp-server/
- Pitch: First-party Blender Foundation MCP server (v1.0.2 shipped Sept 8 pinning MCP SDK <2, v1.0.3 fixed the long-standing screenshot capture tool) — an officially maintained, actively-patched alternative to the community Blender MCP forks currently in use.
- Owner: **Architect** — candidate to standardize on for VironBox/Structa/Hypercube headless Blender render work instead of juggling multiple community forks.

### 4. Blender MCP Server v3 (StraySpark rewrite) — Score 4
- Source: https://www.strayspark.studio/blog/blender-mcp-server-v3-blender-5x-rewrite-404-tools
- Pitch: Community rewrite targeting Blender 5.x LTS and the 2026-07-28 MCP spec revision — 404 tools across 39 categories, ~20x cheaper vision/screenshot context cost, and an agent-driven undo capability.
- Owner: **Architect** — the vision-cost cut and undo support are directly useful for `vironbox-render-flywheel` / `vironbox-render-throughput` iteration loops, but it's unofficial so needs a trial run before adoption over the official server (#3).

### 5. SketchUp MCP Server (Trimble, via Claude for Creative Work) — Score 3
- Source: https://www.engineering.com/now-sketchup-has-an-mcp-server-for-claude-based-3d-modeling/
- Pitch: Trimble's official SketchUp MCP server, bundled into Anthropic's "Claude for Creative Work" launch, giving natural-language control of SketchUp 3D modeling.
- Owner: **Architect** — niche relative to the existing Blender/Revit-centric pipeline, but worth a look for faster massing/concept passes (e.g. `resort-signage-concepts`) where SketchUp is already a common intermediate format.
