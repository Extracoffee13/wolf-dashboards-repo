## Candidates (score ≥ 3)

### 1. Anthropic Agent Skills — Open Standard

**Source:** https://aibusiness.com/foundation-models/anthropic-launches-skills-open-standard-claude  
**Score:** 5 — Drop-in upgrade for existing agent architecture  
**Primary Owner:** Architect

Anthropic released Agent Skills as an open standard: package instructions, scripts, and resources into versioned folders that Claude loads on-demand. Skills work across Claude Web, Claude Code, and the API. Launch partners include Canva, Notion, Figma, and Atlassian. Enterprise orgs get org-wide skill management. This is the canonical skill distribution layer for The Construct — every agent that has a Claude Code skill already benefits automatically.

### 2. Claude Managed Agents — Public Beta

**Source:** https://www.mindstudio.ai/blog/code-with-claude-2026-new-agent-features  
**Score:** 5 — Drop-in upgrade for orchestration infrastructure  
**Primary Owner:** WOLF

Anthropic launched Claude Managed Agents in public beta: a fully managed agent harness with secure sandboxing, built-in tools (browser, code execution, file I/O), and server-sent event streaming. Removes the need to self-host sandboxed execution environments. Claude Code's new "dynamic workflows" feature for large-scale agentic problems ships alongside it. Direct upgrade path for WOLF's command-center orchestration layer.

### 3. AWS Agent Toolkit — General Availability

**Source:** https://aws.amazon.com/about-aws/whats-new/2026/05/agent-toolkit/  
**Score:** 4 — New capability the team would use weekly  
**Primary Owner:** Ledger

AWS shipped the Agent Toolkit for AWS at GA: 60+ MCP servers spanning Lambda, containers, IaC, AI/ML, storage, and analytics. The AWS Data Analytics plugin is purpose-built for data pipelines and BI queries with IAM guardrails and CloudTrail audit logging. Sandboxed Python execution against AWS services is included. Ledger gains a direct, auditable path to Athena/QuickSight/Glue for financial data pipelines; Atlas picks up infrastructure provisioning coverage.

### 5. AgentSkills MCP (zouyingcao/agentskills-mcp)

**Source:** https://github.com/zouyingcao/agentskills-mcp  
**Score:** 3 — Niche but useful  
**Primary Owner:** Architect

Open-source bridge that exposes Anthropic's Agent Skills system to any MCP-compatible agent (not just Claude) using a Progressive Disclosure architecture: skills load on-demand, preserving context windows. Supports stdio, SSE, and HTTP transports. pip-installable, minimal config. Relevant if The Construct ever needs non-Claude agents (e.g., open-weight models) to consume the same skill packages as Claude agents.
