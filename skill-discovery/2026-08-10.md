## Candidates (score ≥ 3)

### 1. Managed Agents auto-discovery of skills from `.claude/skills` in a mounted repo — Score 5
- **Source:** https://platform.claude.com/docs/en/managed-agents/skills
- **Pitch:** When a Claude Managed Agent session mounts a repo via `github_repository`, it now auto-scans the repo's root `.claude/skills/` at session start and makes every skill there available with no upload step and no entry in the agent's skills array — which is exactly the pattern this repo (skill-discovery, praxis-inbox, WOLF dashboards) already runs by hand.
- **Suggested owner:** Architect — this is a direct upgrade to how skills are wired into every Construct agent that runs as a Managed Agent rather than local Claude Code.

### 2. Auto mode now default in Claude Code (Pro/Max/Team) — Score 4
- **Source:** https://claude.com/blog/auto-mode-default-in-claude-code (also covered by TechCrunch, Aug 9, 2026)
- **Pitch:** Starting Aug 14, new Claude Code sessions route every tool call through a safety classifier instead of per-command approval prompts — in Anthropic's own testing it caught a planted dangerous command 89% of the time vs. 13.6% for human reviewers, and it's free (no token surcharge for the classifier).
- **Suggested owner:** Architect — directly affects every scheduled/autonomous routine in the swarm (this one included), since it changes the default approval posture for unattended sessions.

### 3. Self-hosted environments for Claude Code (public beta) — Score 4
- **Source:** https://claude.com/blog/run-claude-code-sessions-on-your-own-compute
- **Pitch:** `claude self-hosted-runner` lets Claude Code cloud sessions execute on infrastructure the org controls, so repo checkouts, build artifacts, and secrets never leave the org's network — only the conversation itself still goes to Anthropic for inference.
- **Suggested owner:** Sentinel — the compliance case (keep Hartley Capital financial data and B9 client data in-house) is squarely a Sentinel call.

### 4. MCP protocol goes stateless (2026-07-28 spec, still propagating) — Score 4
- **Source:** https://blog.modelcontextprotocol.io/posts/2026-07-28/ (also Cloudflare: https://blog.cloudflare.com/mcp-v2/)
- **Pitch:** The MCP spec was rewritten around a fully stateless interaction model, letting servers run in a plain Worker/function with no persistent connection — worth tracking since it will eventually touch every MCP integration this session already depends on (GitHub, Slack, Canva, Gmail, Higgsfield).
- **Suggested owner:** Architect — infrastructure/compatibility watch item, not an immediate action.

### 5. Inference hooks — inline DLP for Claude Enterprise — Score 3
- **Source:** https://claude.com/blog/claude-enterprise-inference-hooks
- **Pitch:** Lets compliance teams inspect and enforce policy on every prompt and tool-call response before it reaches Claude, across chat, Claude Code, and Cowork — a niche fit for anything touching Hartley Capital diligence data, but not a weekly-use tool for most of the swarm.
- **Suggested owner:** Sentinel
