### 1. Claude for Manufacturing — score 4
- Source: https://claude.com/resources/articles/claude-for-manufacturing (Nov 12)
- Pitch: A first-party plugin with 17 skills and 4 connectors for drafting quotes, quality reports and supplier requests. These are the same jobs B9 handles by hand: estimates, reprint/QC notes, and Signs365/WS Display/Gemini supplier orders.
- Owner: **Forge**. Cross-check it against the existing b9-blind-ship-supplier-orders and b9-order-placement-hours gates before adopting any supplier-request skill.

### 2. Self-hosted Claude Managed Agents — score 4
- Source: https://claude.com/resources/articles/self-hosted-claude-managed-agents (Nov 12)
- Pitch: Managed Agents can now run inside our own cloud or on-prem perimeter. That could let Construct agents run next to the agent Mac / VironBox node instead of in Anthropic's sandbox, which matters for credential routing and local file access.
- Owner: **Architect**. Related reading: "Building always-on agents" (https://claude.com/resources/articles/building-always-on-agents, Nov 13).

### 3. Claude Meetings (beta) — score 3
- Source: https://claude.com/resources/articles/claude-meetings (Nov 12)
- Pitch: Claude joins Google Meet calls and creates plans, whiteboards and tasks live. This would help with Lennar division calls, where action items currently get re-typed into decks and emails.
- Owner: **AP**. Team/Enterprise beta only, so plan eligibility needs checking.

### 4. pacxio — score 3
- Source: https://github.com/pacxio-dev/pacxio (repo created ≥ Nov 13, tagged mcp-server)
- Pitch: An open-source packaging design engine that generates editable dielines for folding cartons, mailer boxes and corrugated. It could be a starting point for die-cut and box products in Vector Studio or the CNC/vinyl pipeline.
- Owner: **Vector**. Very new, with 2 stars. Only the description was verified, because repo access is outside this session's scope. Read the license and code before trying it.

### 5. ffmpeg-skill — score 3
- Source: https://www.npmjs.com/package/ffmpeg-skill (repo: https://github.com/kajisho5/ffmpeg-skill), new version published Nov 14
- Pitch: Gives agents a local video editor: 42 FFmpeg tools with a machine-readable contract and an MCP server, and a probe-first / verify-last workflow. This matches our verify-before-claiming discipline for motion decks and social video cutdowns.
- Owner: **Spectra**, with Signal for social.
