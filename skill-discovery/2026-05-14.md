### 1. Claude Managed Agents — Dreaming, Outcomes & Multiagent Orchestration
**Source:** https://claude.com/blog/new-in-claude-managed-agents  
**Published:** 2026-05-06 (Code with Claude SF 2026 launch)  
**Score:** 5 — drop-in upgrade for an existing skill  
**Primary Owner:** WOLF / Architect

Anthropic shipped three Managed-Agent capabilities in one release: **Dreaming** (scheduled memory review that extracts patterns across sessions so agents self-improve over time), **Outcomes** (rubric-based grader that runs in a separate context window and loops the agent until the rubric is satisfied), and **Multiagent Orchestration** (a lead agent fans work to parallel specialist subagents). All three are live in public beta (Dreaming is research preview). For The Construct this is the most impactful release of the cycle — every named agent (Vector, Forge, Signal, Cipher, Spectra, Oracle, Ledger, Atlas, Sentinel, Venture, Equity, Alpha, WOLF, Keystone, Cornerstone, Charlie, Architect, AP) gains access to memory compaction, self-correction loops, and parallel sub-delegation without code changes to the harness.

### 2. FinanceKit MCP
**Source:** https://github.com/vdalhambra/financekit-mcp  
**Published:** v1.2.0 — 2026-04-13  
**Score:** 4 — new capability the team would use weekly  
**Primary Owner:** Ledger / Alpha

A 12-tool MCP server covering real-time equity quotes, batch pricing, crypto data (via CoinGecko), technical indicators (RSI, MACD, Bollinger Bands, SMA/EMA, ADX, Stochastic, ATR, OBV + pattern detection), major-index market overview, and portfolio analysis (sector allocation, concentration risk, diversification scoring, Sharpe ratio, max drawdown). Works with Claude Code, Cursor, and Windsurf via stdio/SSE. Direct drop-in for Hartley Capital's quant workflow: Ledger can run portfolio health checks and Alpha can screen technicals without leaving the agent harness.

### 3. AgentSkills MCP (`mcp-agentskills`)
**Source:** https://github.com/zouyingcao/agentskills-mcp  
**Published:** v0.1.1 — active (Dec 2025, ongoing commits)  
**Score:** 4 — new capability the team would use weekly  
**Primary Owner:** Architect / Keystone

Implements Anthropic's Progressive Disclosure architecture, allowing any MCP-compatible client (Cursor, Cline, etc.) to load Claude's proprietary Agent Skills on-demand rather than holding all skill definitions in context simultaneously. Four MCP tools: `load_skill_metadata_op`, `load_skill_op`, `read_reference_file_op`, `run_shell_command_op`. Install: `pip install mcp-agentskills`. Apache 2.0. For The Construct this unlocks the full skill library on non-Claude clients and reduces context bloat when the harness runs many skills concurrently — directly relevant to Architect's orchestration budget management.

### 4. Claude Agent SDK v0.1.81 — `xhigh` Effort + Hook Event Streaming
**Source:** https://github.com/anthropics/claude-agent-sdk-python/releases  
**Published:** 2026-05-11  
**Score:** 4 — new capability the team would use weekly  
**Primary Owner:** Architect

This minor release (v0.1.81) bundles two high-value additions from v0.1.74: `xhigh` effort level exclusive to Opus 4.7 for maximum reasoning depth on hard tasks, and `include_hook_events` streaming so orchestration layers can observe PreToolUse/PostToolUse/Stop events in real time. Also added: `strict_mcp_config` (ignore global MCP configs for deterministic server sets) and richer `ToolPermissionContext` fields. For The Construct: Architect should enable `xhigh` for WOLF's high-stakes decisions and wire `include_hook_events` into the PRAXIS audit trail for complete observability.
