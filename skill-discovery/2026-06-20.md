## Candidates Scoring ≥ 3

### 1. Anthropic Enterprise-Managed Authorization (EMA) for MCP Connectors
**Source:** https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/  
**Also:** https://www.okta.com/en-ca/newsroom/press-releases/okta-becomes-a-featured-identity-provider-powering-secure-ai-agent-connections-for-claude-enterprise/  
**Published:** June 18–19, 2026 (stable GA)

Zero-touch SSO for MCP connectors: enterprise IT admins provision once through Okta (or any IETF OAuth 2.0 IdP) and every Claude chat, Claude Code, and Cowork session inherits the correct connector access on login — no per-user authorization friction. First stable production implementation of the MCP authorization extension formalized by the IETF OAuth working group. Seven connectors supported at launch: Asana, Atlassian, Canva, Figma, Granola, Linear, Supabase; Slack in progress.

**Score: 5** — drop-in upgrade for enterprise agent operations. Brand 9 Signs and Hartley Capital both run Team/Enterprise plans; this eliminates a recurring access-management toil point for every agent that touches external connectors.  
**Primary owner:** Sentinel

### 2. K-Dense-AI/claude-skills-mcp — Semantic Vector Search for Agent Skills
**Source:** https://github.com/K-Dense-AI/claude-skills-mcp  
**Published:** v1.0.6 — October 2025 (stable); active maintenance confirmed June 2026

MCP server exposing three tools (`find_helpful_skills`, `read_skill_document`, `list_skills`) that perform semantic vector search over ~90 indexed Claude Agent Skills from Anthropic's public repository and K-Dense's own catalog. Any MCP-compatible agent can query it to discover the right skill for an arbitrary task description — eliminating manual skill wiring. Two-package architecture: lightweight frontend (<5 s cold start), heavier vector backend downloads in background.

**Score: 4** — new capability the team would use weekly. Vector can use this as a skill-routing layer; WOLF can wire it to the agent mesh so any agent auto-discovers the correct skill for an inbound task, rather than relying on hardcoded skill lists.  
**Primary owner:** Vector

### 3. MCP 2026 Release Candidate — Tasks, MCP Apps, Auth Hardening
**Source:** https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/  
**Published:** RC announced June 2026; final spec targets 2026-07-28

Largest MCP specification revision since launch. Key additions relevant to The Construct: (a) **Tasks** — first-class async job objects with lifecycle events, replacing ad-hoc polling; (b) **MCP Apps** — bundled server + UI manifests enabling one-click agent deployment; (c) **Extensions framework** — stable versioned extension slots replacing informal spec drafts; (d) **Authorization hardening** — formalizes the EMA pattern above as a core spec primitive; (e) **Formal deprecation policy** — gives teams a predictable migration window.

**Score: 4** — reshapes multi-agent orchestration architecture. The Construct's agent mesh will need to adopt Tasks for async flows and prepare for MCP Apps packaging. Architect should review the RC and flag breaking changes before the July 28 GA.  
**Primary owner:** Architect

### 4. skillforge-mcp — Self-Evolving Agent Skill Accumulation (PyPI)
**Source:** https://pypi.org/project/skillforge-mcp/  
**Published:** April 3, 2026 (most recent notable PyPI entry in discovery window)

MCP server that gives an agent persistent memory for skills it has learned or been taught — storing, indexing, and retrieving skill definitions across sessions. Pitched as "your AI agent learns and evolves — one skill at a time." Enables agents to accumulate domain-specific procedures without retraining or hardcoded prompt injection.

**Score: 3** — niche but useful. Relevant for Forge's agent-tooling mandate: could provide a lightweight persistent skill store without requiring a full vector DB, especially useful for Brand 9 Signs creative-workflow agents that learn client-specific conventions over time.  
**Primary owner:** Forge

### 5. skill-to-mcp — Bridge Claude Skills to MCP Resources (PyPI)
**Source:** https://pypi.org/project/skill-to-mcp/  
**Also:** https://skill-to-mcp.readthedocs.io/en/latest/  
**Published:** Active 2025–2026

Converts Claude Skills (`.md`-based, following Anthropic's skills format) into MCP server resources, making any existing Claude Code skill queryable via the Model Context Protocol. Enables repackaging The Construct's internal skills for use by non-Claude MCP clients (Cursor, VS Code Copilot, Codex, Gemini) and for exposure through centralized MCP registries.

**Score: 3** — niche but useful. Charlie or Cornerstone could use this to publish Brand 9 Signs' internal skills (e.g., sign-quoting, brand-brief generation) as MCP endpoints, broadening their reach beyond Claude Code sessions.  
**Primary owner:** Charlie
