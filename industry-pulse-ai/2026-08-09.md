# AI/Agent Ecosystem Pulse — 2026-08-09

- **Anthropic MCP ecosystem hits scale, spec bump to 2026-07-28.** Claude now lists 950+ MCP servers in the connectors directory (used by millions daily), and Claude/Claude Code have adopted the new MCP 2026-07-28 spec — stateless core, stronger OAuth/OIDC auth, versioned extensions. Claude Code itself shipped a VSCode Focus view, sandbox credential masking, gateway spend-limit warnings, and workspace trust prompts for `claude agents`. Source: [Releasebot — Claude Code updates](https://releasebot.io/updates/anthropic/claude-code), [Gradually.ai changelog](https://www.gradually.ai/en/changelogs/claude-code/). **Applicable to The Construct: yes** — the OAuth/OIDC + versioned-extensions bump is worth checking against our own MCP servers (Hermes, WOLF) before the old spec is deprecated; spend-limit gateway support is directly useful for cost control on agent fleets.

- **Vertical MCP servers now covering our core stack — signage, CRM, and voice.** Three digital-signage CMS platforms (CastHub, Screenly, Revel Digital) now ship production-grade native MCP servers; Pipedrive launched a native CRM MCP server; 3CX added a native MCP endpoint plus a Customer Service AI Agent for voice. Sources: [CastHub signage MCP vendor guide](https://cast-hub.com/digital-signage-mcp-vendors/), [Pipedrive MCP launch](https://www.pipedrive.com/en/newsroom/pipedrive-launches-native-mcp-server-bringing-crm-workflows-directly-into-ai-assistants), [3CX native MCP](https://www.3cx.com/blog/releases/native-model-context-protocol/). **Applicable to The Construct: yes** — signage-industry MCP servers are directly relevant to Brand 9 Signs; worth a quick eval of CastHub/Screenly MCP against our current manual signage workflows.

- **Perplexity "Computer" agent platform live and multi-model.** Perplexity's $200/mo "Computer" product orchestrates 19 different models to run long, background agentic workflows (now also on Windows), on the back of a $200M raise (~$20B valuation). Glean, competing in enterprise AI search/agents, doubled ARR to $200M and raised $150M Series F at $7.2B. Sources: [VentureBeat — Perplexity Computer launch](https://venturebeat.com/technology/perplexity-launches-computer-ai-agent-that-coordinates-19-models-priced-at), [Glean Series F](https://www.glean.com/press/glean-raises-150m-series-f-at-7-2b-valuation-to-accelerate-enterprise-ai-agent-innovation-globally). **Applicable to The Construct: maybe** — no direct replacement need, but Perplexity's multi-model orchestration approach is a competitive signal for anyone selling "agent platform" positioning; worth a Scout flip-trigger note.

- **Frontier model cadence keeps compressing.** Google shipped Gemini 3.6 Flash (cheaper/faster tool-calling), Meta released Muse Spark 1.2 and (earlier) Llama 5 with self-improving reasoning claims, OpenAI's GPT-5.6-powered "ChatGPT Work" targets autonomous document/report generation from team context, and Alibaba's Qwen3.8 Max landed Aug 2. Sources: [llm-stats.com AI news](https://llm-stats.com/ai-news), [Digital Applied — August 2026 tracker](https://www.digitalapplied.com/blog/ai-model-releases-august-2026-tracker). **Applicable to The Construct: no** — none require an immediate stack change, but ChatGPT Work's "autonomous report from team context" is worth watching as a Keystone competitive note against our own agent-authored deliverables.

- **Agent-architecture literature is consolidating around "context engineering."** Recent arXiv work (2603.09619, "Context Engineering: From Prompts to Corporate Multi-Agent Architecture") frames context as the agent's operating system, proposing five quality criteria — relevance, sufficiency, isolation, economy, provenance. A companion paper (2602.10479) tracks the field's shift from prompt–response to goal-directed agentic software architecture. Sources: [arXiv 2603.09619](https://arxiv.org/abs/2603.09619), [arXiv 2602.10479](https://arxiv.org/html/2602.10479v1). **Applicable to The Construct: yes** — the five context-quality criteria (relevance/sufficiency/isolation/economy/provenance) are a usable checklist against our own skill/CLAUDE.md context design.
