# AI / Agent Ecosystem Pulse — 2026-11-27

Scope: Anthropic, frontier labs, MCP registries/launches, agent-platform funding, arXiv (cs.MA / agents).
Window note: the last 24h was quiet (US Thanksgiving). Items older than 24h are marked with their date. Claims from aggregator sites only are flagged.

1. **Canva MCP server is generally available, with self-serve developer access (reported Nov 26)**
   Source: https://www.canva.dev/blog/developers/canva-mcp-ga/ · https://mediabrief.com/canva-opens-mcp-server-to-all-developers/
   Summary: Canva's remote MCP server (design creation, brand templates, export) is now GA. It now sits in one Canva Developers SDK alongside the Apps SDK and Connect APIs.
   **Applicable to The Construct: yes.** The Canva MCP is already connected in our sessions. Now that it's GA, it can serve as a stable production path for Lennar decks, social posts and brand-template signage mockups, without hand work in the Canva UI.

2. **Claude Code MCP Tasks + Elicitations: long-running tools that can pause and ask the user (public beta; launched Oct 23, coverage continuing this week)**
   Source: https://upstash.com/blog/claude-code-mcp-tasks.md · https://aicatchup.com/news/claude-code-mcp-tasks-public-beta
   Summary: MCP tools can now run for hours as durable tasks and ask the user for input mid-run. This needs Claude Code v2.1.304 or later and works only in the CLI for now. One aggregator (emergent.sh) claims Tasks went GA on Nov 24, but no other source confirms it, so treat Tasks as beta.
   **Applicable to The Construct: yes.** This fits Blender/VironBox renders, Hermes worker-queue jobs and CNC compile jobs. It could replace our current "launch, then poll the worker queue" pattern with one durable task that asks for Bobby's approval at the gates.

3. **Anthropic, November: Fable 5.2 / Mythos 5.2 (Nov 9), Claude Meetings + Sheets + Whiteboards beta (Nov 10), self-hosted Managed Agents (Nov 12)**
   Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/ · https://releasebot.io/updates/anthropic/claude-developer-platform
   Summary: New top-tier models with 1M-token context, Claude joining video calls to produce plans and tasks, and Managed Agents that can now run on your own infrastructure.

Claude Meetings (Team/Enterprise only) could turn client calls such as Lennar reviews into deck-revision tasks.
