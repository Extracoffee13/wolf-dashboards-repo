# Industry Pulse — AI/Agent Ecosystem — 2026-07-20

- **Anthropic — Cowork goes mobile/web + enterprise-managed MCP access.** ([9to5Mac](https://9to5mac.com/2026/07/13/anthropic-expanding-claude-cowork-to-mobile-and-web-details-here/), [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes)) Cowork sessions are moving from desktop-only to a remote, cross-device model (Max plan first) with scheduled tasks that run with no device online, plus enterprise-managed MCP connector provisioning (starting with Okta) for zero-touch access across chat/Code/Cowork. **Applicable to The Construct: yes** — this is the exact substrate Bobby's C-Suite already runs on; cross-device Cowork + centralized MCP provisioning could simplify how the Slack/Gmail/Drive/Canva connectors are managed across agents.

- **Revid.ai ships an MCP server for programmatic video production.** ([MarTech Series](https://martechseries.com/video/leading-ai-video-generation-platform-revid-ai-launches-mcp-server-and-command-line-tool-giving-ai-agents-direct-access-to-video-production/)) New MCP exposes `render_video`, `clone_voice`, `schedule_publish`, and `publish_now` tools, letting agents render and auto-publish video end-to-end. **Applicable to The Construct: maybe** — overlaps with the existing Higgsfield video/voice pipeline (Vector's toolkit); worth a bake-off only if Revid's scheduling/publish-direct tools cover a gap Higgsfield doesn't (e.g. native multi-platform `publish_now`).

- **xAI folds into "SpaceXAI," ships Grok 4.5 trained on Cursor agent data.** ([ThursdAI](https://thursdai.news/releases/2026-07)) Grok 4.5 (1.5T-param MoE, $2/$6 per M tokens) launched July 8 as the first flagship under the merged SpaceXAI brand, trained on real Cursor agent-interaction traces rather than generic code corpora. **Applicable to The Construct: no** — coding-agent-tuned model, not a fit for the marketing/ops workloads the Construct runs, but worth tracking as a signal that frontier labs are training directly on agent-trajectory data.

- **Perplexity raises $60M extension at $3.5B, Glean raises $180M Series D at $2.7B.** ([TechTimes](https://www.techtimes.com/articles/318028/20260608/perplexity-raises-200-million-comet-ai-browser-agent-economy-front-door.htm), [LinkedIn/Analytics India](https://www.linkedin.com/posts/analytics-india-magazine_enterprise-ai-platform-glean-has-raised-150-activity-7338428240581009409-8IMB)) Perplexity is pushing Comet (its agentic browser) as the "front door" to the agent economy; Glean is scaling enterprise search/agent orchestration. **Applicable to The Construct: no** — adjacent competitive-intel signal only; neither displaces a current Construct tool.

- **"Context Engineering: From Prompts to Corporate Multi-Agent Architecture"** ([arXiv:2603.09619](https://arxiv.org/abs/2603.09619)) Proposes context engineering as its own discipline — five quality criteria (relevance, sufficiency, isolation, economy, provenance) for what an agent sees before it decides — surveying Google ADK, Anthropic, and LangChain architectures. **Applicable to The Construct: yes** — directly informs how PRAXIS inbox packets, WOLF live-data, and per-agent skill context should be scoped/pruned so agents aren't drowning in irrelevant context.
