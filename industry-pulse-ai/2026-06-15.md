## 5. "Context Engineering" Paper — Context as the Agent's Operating System

**Source:** [arXiv:2603.09619 — Context Engineering: From Prompts to Corporate Multi-Agent Architecture](https://arxiv.org/abs/2603.09619v1)

Introduces context engineering as a standalone discipline: designing and managing the full informational environment in which an agent operates, with five quality criteria — relevance, sufficiency, isolation, economy, and provenance — and frames context as the agent's OS rather than a prompt prefix.

**Applicable to The Construct: YES** — Directly actionable for WOLF prompt architecture; the five criteria provide a concrete audit framework for every system prompt in the current agent stack, especially context passed between nested sub-agents.
