# Industry Pulse — AI/Agent Ecosystem — 2026-08-30

- **Claude Code Aug 29 batch update** — [explainx.ai](https://explainx.ai/blog/claude-code-weekly-update-faster-startup-token-visibility-august-2026) / [Releasebot](https://releasebot.io/updates/anthropic/claude-code) — Anthropic shipped a cluster of Claude Code fixes: CLI starts before the sandbox loads, Linux download shrinks to ~75MB, `/cost`/`/usage`/`/tasks` get richer token detail, and GitLab merge-request support lands. Applicable to The Construct: **yes** — directly upgrades the CLI stack Cowork/Hermes agents already run on; no workflow change needed, just take the update.

- **Rechat ships MCP Server for real estate CRM** — [WAV Group](https://www.wavgroup.com/2026/08/04/rechats-mcp-server-points-to-a-connected-agentic-future-for-real-estate/) — Rechat's new MCP server exposes contacts, marketing tools, and transaction/MLS data to Claude and ChatGPT, signaling brokerages standardizing on MCP for agentic workflows. Applicable to The Construct: **maybe** — relevant pattern for ANS/real-estate-adjacent site-system work (Lennar Atlas, structa) if we ever need live MLS/CRM data instead of static builder data.

- **DAM vendors (Frontify, Acquia, Aprimo) now ship native MCP servers** — [Frontify](https://www.frontify.com/en/guide/dam-mcp) / [Acquia](https://docs.acquia.com/acquia-dam/release/2026-08-06/98951-acquia-dam-july-2026) — Digital asset management platforms are exposing asset search, metadata, and CDN URLs as MCP tools so agents can pull brand assets by natural language instead of a UI. Applicable to The Construct: **yes** — would replace ad-hoc asset lookups for B9/Vector brand work if we adopt one of these DAMs; worth evaluating vs. our current file-based asset flow.

- **Perplexity nears $750M ARR, Nvidia in talks for $30B+ round** — [TechFundingNews](https://techfundingnews.com/nvidia-reportedly-eyes-perplexity-at-a-30b-valuation-as-ai-search-becomes-an-agent-business/) — growth driven by the Feb 2026 "Computer" agent product and usage-based pricing layered on subscriptions. Applicable to The Construct: **no** — competitive-landscape signal only, not a tool we'd adopt.

- **"Context Engineering: From Prompts to Corporate Multi-Agent Architecture" (arXiv 2603.09619)** — [arxiv.org/abs/2603.09619](https://arxiv.org/abs/2603.09619) — proposes context engineering as a discipline with five quality criteria (relevance, sufficiency, isolation, economy, provenance) for structuring what an agent sees, drawing on Google/Anthropic/LangChain architectures. Applicable to The Construct: **yes** — the five criteria are a useful checklist for auditing our own agent skill files and memory/context design (e.g. Praxis inbox, Self-Improving Loop).
