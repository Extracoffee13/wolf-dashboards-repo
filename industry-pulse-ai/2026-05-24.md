- **Anthropic: Claude Opus 4.7 GA + Claude Design launch**
  Source: https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/
  Opus 4.7 hits 87.6% on SWE-Bench Verified (up 13pts from 4.6) with 3× higher-res vision at the same price; Anthropic simultaneously launched Claude Design (Labs), enabling collaborative generation of visual outputs—designs, prototypes, slides, one-pagers. Also: multiagent orchestration (lead agent delegates to specialists on shared filesystem) and Dreaming (session-review memory) entered research preview.
  **Applicable to The Construct: YES** — Opus 4.7 directly upgrades any Claude-backed agent we run (WOLF, AP, etc.); Claude Design is a strong candidate to replace or augment our current Canva/manual deck workflow for client presentations and signage content proposals.

- **arXiv: "Context Engineering: From Prompts to Corporate Multi-Agent Architecture" (2603.09619)**
  Source: https://arxiv.org/abs/2603.09619v1
  Defines context engineering as a formal discipline: designing the full informational environment in which an agent acts, governed by five quality criteria—relevance, sufficiency, isolation, economy, and provenance. Frames context as the agent's operating system, not just a prompt prefix.
  **Applicable to The Construct: YES** — Directly actionable for improving WOLF and PRAXIS agent prompts; the five criteria map cleanly onto how we structure system prompts, tool outputs, and memory injection for The Construct's agent stack.
