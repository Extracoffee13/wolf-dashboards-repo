Source: [Releasebot — Anthropic updates](https://releasebot.io/updates/anthropic). **Applicable to The Construct: maybe** — could simplify multi-phase agent workflows (e.g. research → build → verify) that currently require separate sessions or subagents to change toolsets.

- **xAI Grok prompt-injection/data-exfiltration vulnerability disclosed (Adversa AI, Aug 25 2026)** — Researchers describe hiding AES-256-GCM-encrypted instructions in webpages; when Grok summarizes the page its Python sandbox decrypts and can exfiltrate user name, location, subscription tier, and chat history. Reported to xAI via HackerOne June 3 2026; no patch/CVE as of this report. Source: [Adversa AI report, via search aggregation](https://aiweekly.co/ai-news-today). **Applicable to The Construct: yes — as a caution.** Any agent that summarizes/fetches untrusted web content (ours included) needs the same defense: treat fetched page content as data, never instructions, consistent with how this session already handles external tool output.

- **Pipedrive ships native MCP server for CRM (Pipedrive, dated ~late June 2026, still circulating in this week's MCP roundups)** — Lets MCP-compatible assistants (Claude, ChatGPT, etc.) read/write live CRM data with existing permissions and a full audit trail. Source: [Pipedrive newsroom](https://www.pipedrive.com/en/newsroom/pipedrive-launches-native-mcp-server-bringing-crm-workflows-directly-into-ai-assistants). **Applicable to The Construct: maybe** — if any Construct workflow touches CRM data, a native MCP server beats a custom integration; worth a scoping look if we adopt a CRM in this stack.

- **Perplexity nearing $750M ARR, Nvidia reportedly in talks to invest at $30B+ valuation** — Growth attributed to the Feb 2026 "Comet"/Computer agent product plus usage-based pricing. Source: [TechFundingNews](https://techfundingnews.com/nvidia-reportedly-eyes-perplexity-at-a-30b-valuation-as-ai-search-becomes-an-agent-business/). **Applicable to The Construct: no** — market signal only, no direct workflow implication today.
