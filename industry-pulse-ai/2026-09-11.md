# Industry Pulse — AI/Agent Ecosystem — 2026-09-11

- **[DeepSeek releases V4.1-Flash, claims it beats flagship V4-Pro](https://siliconangle.com/2026/09/10/deepseek-releases-v4-1-flash-says-it-outperforms-flagship-v4-pro/)** — MIT-licensed, 552B-param MoE, 1M context, multimodal, priced at $0.15/M input tokens; DeepSeek is routing all V4-Pro API traffic to it from Sept 14 at the cheaper rate. Applicable to The Construct: yes — confirms the frontier cadence is accelerating; worth a standing check that our default model references (Claude Code, MCP tool defs) track the newest GA Claude rather than lagging.

- **["Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents"](https://arxiv.org/abs/2609.00006)** — 83-page source-code study of eleven production coding-agent harnesses (Claude Code, Codex CLI, Gemini CLI, OpenHands, Aider, Hermes, and others), formalizing "agent = model + harness" and naming harness engineering as a discipline. Notably includes a system literally named "Hermes" among the eleven studied. Applicable to The Construct: yes — directly relevant vocabulary/patterns for how we structure our own Hermes agent harnesses (tool surfaces, context management, safety controls); worth a read for whoever owns hermes-agent-control conventions.

- **[Claude Code September changelog: MCP session-reliability fixes](https://releasebot.io/updates/anthropic/claude-code)** — Fixed SDK-provided MCP servers sometimes missing on the first turn, corrected `claude mcp add --header`/`add-json` help text, and fixed `/mcp reconnect` on Remote Control showing a generic error instead of the real remedy. Applicable to The Construct: yes — these are exactly the MCP flakiness symptoms (servers missing first turn, unclear reconnect errors) that show up in our own Cowork/Hermes MCP wiring; worth updating if any local tooling worked around these bugs.

- **[Perplexity's agent product "Computer" scaling fast](https://sacra.com/c/perplexity/)** — Perplexity hit an estimated $750M annualized revenue in August 2026, growth largely credited to its February 2026 agent product launch (Computer) and a $200M raise for its Comet AI browser.
