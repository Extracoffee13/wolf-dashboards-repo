1. **Google Gemini 4 Neon (Nov 18)**: https://venturebeat.com/technology/google-launches-gemini-4-neon-with-opus-5-5-level-coding-performance-at-25-lower-api-token-prices

2. **Claude Code 2.1.327–2.1.328 (Nov 17–19)**: https://releasebot.io/updates/anthropic/claude-code · https://www.gradually.ai/en/changelogs/claude-code/
   `claude mcp add-json` can now read MCP server JSON from stdin, so tokens stay out of the command line and shell history. `/install-github-app` now asks before changing a repo. Prompt caching improved for Code Mode sessions that have MCP servers.
   **Applicable to The Construct: yes.** Use the stdin path for the vendor-portal and Higgsfield/Canva MCP credentials on the agent Mac (matches vironbox-credential-routing). The caching gain cuts cost on MCP-heavy routines like this one.

3. **Anthropic: Fable 5.2 / Mythos 5.2 plus self-hosted Managed Agents (Nov 9–17)**: https://releasebot.io/updates/anthropic/claude-developer-platform · https://www.anthropic.com/news

4. **MCP launches: Zinc hosted retail-order MCP and Proof x401 agent-authorization MCP (Nov 18)**: https://www.prweb.com/releases/zinc-launches-hosted-mcp-server-and-retail-order-apis-for-ai-shopping-agents-in-2026-302942962.html · https://www.globenewswire.com/news-release/2026/11/18/3405765/0/en/proof-launches-its-mcp-in-chatgpt-starting-with-x401-so-ai-agents-can-prove-who-they-act-for-and-what-that-person-approved.html
   Zinc lets agents place purchases across marketplaces. Proof gives agents a signed record of who they act for and what that person approved. No new video-gen, voice, scheduling, DAM, signage or real-estate MCP servers turned up in the window.
   **Applicable to The Construct: maybe.** x401-style signed approvals could formalize the owner-confirmation gate in b9-blind-ship-supplier-orders. Zinc is no use for our supplier mix (Signs365, WS Display and Gemini aren't marketplaces).

5. **arXiv this week, agent memory**: https://arxiv.org/abs/2611.17068 · https://arxiv.org/abs/2611.09721 · https://arxiv.org/abs/2611.00060
   - *Discovering Effective Agent Memory Designs through Program Evolution*: keeping raw conversations as retrievable evidence helps, and its query-intent module improved accuracy in all five memory systems it was added to.
   - *MemoryDojo*: a benchmark of poisoning attacks that go through an agent's persistent memory.
   - *Memorix*: a versioned memory store that separates choosing memories from writing them into the prompt, so selections can be repeated.
   **Applicable to The Construct: yes.** MemoryDojo is a direct threat model for PRAXIS_INBOX and skills memory, which agents write and later sessions trust. Memorix-style versioning would make lessons auditable and reversible.
