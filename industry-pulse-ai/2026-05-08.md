- **Claude Code ships /resume PR URL paste + MCP stdio fix**
  Source: [github.com/anthropics/claude-code/releases](https://github.com/anthropics/claude-code/releases)
  Pasting a PR URL into the `/resume` search box now resolves the originating session (GitHub, GitLab, Bitbucket); also fixed MCP stdio servers receiving corrupted arguments when `CLAUDE_CODE_SHELL_PREFIX` contains shell metacharacters. Bedrock service-tier selection added via `ANTHROPIC_BEDROCK_SERVICE_TIER`.
  **Applicable to The Construct: yes** — the `/resume`-by-PR-URL feature directly tightens the Claude Code ↔ GitHub loop used in our review and patch workflows.

- **Higgsfield + MiniMax MCP servers: agentic video/image/voice now one tool call away**
  Sources: [mcp.directory/blog/higgsfield-mcp-guide](https://mcp.directory/blog/higgsfield-mcp-guide) · [pulsemcp.com/servers/minimax-multimodal](https://www.pulsemcp.com/servers/minimax-multimodal)
  Higgsfield MCP (launched Apr 28) returns 4K stills or 15-second 1080p clips; MiniMax Multimodal MCP adds TTS + voice cloning; invideo MCP generates full-length scripted videos with AI voiceovers. All expose remote MCP endpoints consumable by Claude agents.
  **Applicable to The Construct: yes** — would replace our current manual Higgsfield/video handoff with an in-agent generation loop; voice cloning via MiniMax opens narrated-asset production at scale.

- **arXiv: "Context Engineering" formalised as standalone discipline (2603.09619)**
  Source: [arxiv.org/abs/2603.09619](https://arxiv.org/abs/2603.09619) · [arxiv.org/html/2604.18071v1](https://arxiv.org/html/2604.18071v1)
  Vishnyakova (Mar 2026) frames context engineering — designing the full informational environment for agent decision-making — as distinct from prompt engineering. Companion paper (2604.18071) studies 70 public agent projects: hybrid, hierarchical, file-persistent context designs dominate; context handling has become an infrastructure concern.
  **Applicable to The Construct: yes** — directly informs how we architect PRAXIS agent memory, inbox routing, and task-handoff schemas; validates our move toward structured inbox packets over free-form prompts.
