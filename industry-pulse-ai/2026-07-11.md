# Industry Pulse — AI/Agent Ecosystem — 2026-07-11

- **[Anthropic Claude Code / Cowork updates](https://releasebot.io/updates/anthropic/claude-code)** — Claude Code shipped Claude-in-Chrome as GA, background notifications, draft-PR handoff, and a new `/dataviz` skill; Cowork expanded to web/mobile with Microsoft 365 write tools (draft/send email, manage calendar, edit OneDrive/SharePoint). **Applicable to The Construct: yes** — the MS365 write tools and Cowork mobile parity could replace ad-hoc scripts we use for calendar/file handoffs between agents and staff.

- **[DAM vendors shipping native MCP servers](https://ci-hub.com/blog/turning-dam-into-mcp-server)** — Aprimo launched "Agentic DAM" (Mar 2026) and an official MCP server (May 2026); Cloudinary, Frontify, and Adobe now ship native MCP servers, letting Claude/ChatGPT query brand asset libraries directly. **Applicable to The Construct: yes** — this is squarely our signage/DAM lane; worth trialing one of these MCP servers against our asset library instead of building a custom connector.

- **[Frontier model releases: Grok 4.5, GPT-5.6, DeepSeek V4](https://llm-stats.com/llm-updates)** — xAI's Grok 4.5 (Jul 8) targets unfiltered/creative use with native X grounding; OpenAI's GPT-5.6 (Jul 9) is the new ChatGPT default with a cheaper "Terra" tier; DeepSeek released V4-Pro/V4-Flash MoE models with 1M-token context tuned for long-running agentic tasks; Meta shipped Muse Spark 1.1, its first paid model, tuned for agentic coding. **Applicable to The Construct: maybe** — DeepSeek V4's cheap long-context agentic tier is worth a cost/quality bake-off against Sonnet 5 for our high-volume, low-stakes drafting tasks.

- **[Cognition ships Devin Security Swarm + Devin Desktop](https://www.prnewswire.com/news-releases/cognition-launches-devin-security-swarm-to-tackle-the-vulnerability-backlog-302814800.html)** — Devin Security Swarm (Jul 1) triages and validates vulnerabilities at runtime; Devin Desktop adds "Spaces" for grouping agents by project with shared context across PRs/files/tasks. Separately, Perplexity Computer is now embedded directly in Microsoft 365 apps. **Applicable to The Construct: no** — not our stack, but the "Spaces" shared-context pattern is a useful design reference for our own multi-agent (PRAXIS) coordination.

- **[arXiv: "Context Engineering: From Prompts to Corporate Multi-Agent Architecture"](https://arxiv.org/abs/2603.09619)** — Proposes context engineering as a discipline for designing an agent's full informational environment, scored on five criteria: relevance, sufficiency, isolation, economy, and provenance — framing context as the agent's "operating system." **Applicable to The Construct: yes** — the five-criteria rubric is directly usable to audit what we feed PRAXIS agents (inbox blocks, task context) for bloat and provenance gaps.
