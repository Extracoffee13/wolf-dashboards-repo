# Industry Pulse — AI/Agent Ecosystem — 2026-09-17

- **[Claude Code changelog, Sept 2026](https://code.claude.com/docs/en/changelog)** — Anthropic shipped a run of MCP-reliability fixes: synced plugin MCP servers now reconnect properly on remote-session resume, disconnected/upgraded MCP servers no longer wipe the model's prior reasoning when the tool list re-renders, and re-auth errors now tell the user to run `/mcp`. **Applicable to The Construct: yes** — directly affects the stability of every Cowork/Claude Code session running our MCP stack (Higgsfield, Slack, GitHub, Canva); worth confirming our synced plugins pick up the fix on next session restart.

- **[Glean raises $150M Series F at $7.2B](https://www.glean.com/press/glean-raises-150m-series-f-at-7-2b-valuation-to-accelerate-enterprise-ai-agent-innovation-globally)** — Enterprise search/agent platform Glean closed a $150M round nine months after its last raise, crossing $100M ARR. **Applicable to The Construct: no** — enterprise-search positioning doesn't overlap our owned-presence/archviz/signage stack, but signals continued capital flowing into agent-platform incumbents we compete adjacent to for attention/mindshare.

- **[Context Engineering: From Prompts to Corporate Multi-Agent Architecture (arXiv)](https://arxiv.org/abs/2603.09619)** — Proposes context engineering as a discipline distinct from prompt engineering, with five quality criteria (relevance, sufficiency, isolation, economy, provenance) for what an agent's context window should contain. **Applicable to The Construct: yes** — directly relevant to how we scope per-agent skill/context loading across the Construct's growing skill library (100+ skills now loaded per session); worth auditing our skill-listing bloat against the "economy" criterion.
