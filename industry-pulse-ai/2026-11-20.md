# AI / Agent Ecosystem Pulse — 2026-11-20

Window: last ~24–72h, with a few earlier November items that still matter. Sources are web search results. Several are aggregators, so check the official pages before acting on prices or dates.

- **Google ships Gemini 4 Neon (Nov 18)** — https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/
  A mid-tier Gemini 4 model (between Carbon and Hydrogen) built for software engineering and knowledge work. It has a 1M-token context and is live in the Gemini API, AI Studio and Antigravity. One report puts it at about $3/$15 per M tokens, and TestingCatalog has it at #2 on the Vals Index, 0.4 pts behind Claude Fable 5.2 at under half the cost per task (not confirmed by Google).
  **Applicable to The Construct: maybe** — it's a cheap second engine for Hermes bulk work (claims sweeps, alt-text, page drafts), and it gives a new target for B9 AI-shelf measurement (is Gemini 4 Neon naming Brand 9?).

- **Claude Code v2.1.327–328 + hook changes (Nov 17–19)** — https://code.claude.com/docs/en/changelog
  Shorter tool descriptions cut Code Mode token use. `claude mcp add-json` now takes JSON on stdin, which keeps tokens off the command line. mcp_tool hooks gain `"onFailure": "block"`.
  **Applicable to The Construct: yes** — the stdin add-json matches vironbox-credential-routing (no secrets in argv or shell history). The `onFailure: block` hook is a cheap way to turn our gates (claims-truth, blind-ship) into hard stops instead of advisories.

- **Anthropic self-hosted Managed Agents (Nov 12) + Claude Data default-on today (Nov 20)** — https://releasebot.io/updates/anthropic/claude-developer-platform · https://casrai.org/news/anthropic-claude-whiteboards-sheets-data-launch-2026
  Managed Agents can now run on your own infrastructure, so agent data stays in-house. Claude Data (formerly Dashboards) is GA and turns on by default for Enterprise today, and Claude Meetings, Whiteboards and Sheets are in beta (launched Nov 10).
  **Applicable to The Construct: maybe** — self-hosted Managed Agents could replace part of the hand-rolled Hermes worker queue on the agent Mac. Claude Data could be an alternative to the hand-built V6 dashboard panels. Worth a scoped trial and no migration yet.

- **New MCP servers: Zinc retail orders, Tutorial AI video, Proof identity (Nov 17–18)** — https://www.prweb.com/releases/zinc-launches-hosted-mcp-server-and-retail-order-apis-for-ai-shopping-agents-in-2026-302942962.html · https://customerthink.com/tutorial-ai-opens-its-mcp-server-to-all-users-letting-chatgpt-claude-and-gemini-build-software-tutorials-from-screen-recordings/ · https://www.globenewswire.com/news-release/2026/11/18/3405765/0/en/proof-launches-its-mcp-in-chatgpt-starting-with-x401-so-ai-agents-can-prove-who-they-act-for-and-what-that-person-approved.html
  Zinc offers a hosted MCP for placing Amazon, Walmart and Home Depot orders. Tutorial AI turns screen recordings into narrated tutorial videos over MCP. Proof's x401 lets agents prove who they act for and what was approved. No new signage, DAM or real-estate MCP servers turned up.
  **Applicable to The Construct: maybe** — Tutorial AI could produce Vector Studio how-to videos for product pages. Proof/x401 is the pattern to watch for owner-approved supplier orders (b9-blind-ship gate). Zinc is a no for now, since our suppliers aren't on it.

- **Arxiv this month: StateGate, "Simplicity Goes Far", PromptOps** — https://arxiv.org/abs/2611.01585 · https://arxiv.org/abs/2611.22605 · https://arxiv.org/abs/2611.07123
  StateGate turns prompt constraints for long-chain agents into symbolic gates that a deterministic runtime enforces. "Simplicity Goes Far" shows a basic demo-sampling baseline matches fancy prompt optimizers and asks papers to report token and rollout cost. PromptOps covers ongoing prompt maintenance for LLM-as-judge systems.
  **Applicable to The Construct: yes** — StateGate backs our existing gate-first design (rules run in code, not in the prompt). PromptOps applies to the B9 AI-shelf and Mallard scoring judges, which drift over time.
