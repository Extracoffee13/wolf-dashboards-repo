- **Canva MCP is generally available (self-serve), but there is no service-account auth.**
  Source: https://www.canva.dev/blog/developers/canva-mcp-ga/
  Summary: Canva's MCP server is now GA for any developer, with new APIs. Auth is per-user OAuth only: there is no org-level or service-account login, and the tools inherit the signed-in user's design permissions and plan.
  Applicable to The Construct: **yes**. It is already wired into our sessions as the Canva connector, so it can take over manual Canva steps for B9 decks and social graphics. Unattended Hermes/cron agents still need Bobby's own OAuth grant, so treat it as a "Bobby-signed-in" tool, not a headless one.
