# Industry Pulse — AI/Agent Ecosystem — 2026-07-03

- **Anthropic: Claude Sonnet 5 GA + enterprise-managed MCP connector auth.** [Anthropic Newsroom](https://www.anthropic.com/news) / [Claude Code changelog](https://code.claude.com/docs/en/whats-new) — Claude Sonnet 5 (1M context, 128k max output, promo pricing $2/$10 per MTok through Aug 31) is now the default Claude Code model, and Anthropic shipped enterprise-managed MCP connector access (starting with Okta) so admins can provision connectors like Asana, Atlassian, Canva, Figma, Granola, Linear, and Supabase once with zero-touch access for users. **Applicable to The Construct: yes** — zero-touch MCP provisioning simplifies rolling connector access out to the team without per-user OAuth friction; worth adopting once Slack support lands.

- **Digital signage vendors are shipping native MCP servers.** [Digital Signage MCP Vendor Guide 2026](https://cast-hub.com/digital-signage-mcp-vendors/) — CastHub, Screenly, and Revel Digital now publish production-grade MCP servers (media/players/content/schedules/analytics); Fugo and NoviSign have beta MCP; Korbyt has a public roadmap item for a hosted, tenant-scoped MCP server (Claude/Cursor/ChatGPT as named targets) with a June 30, 2026 ETA, though we found no confirmation it has actually shipped yet. **Applicable to The Construct: yes** — this is directly in-lane for a signage/motion-decks business; worth a follow-up check on whether Korbyt's server actually went live, and whether CastHub/Screenly/Revel Digital MCP servers could plug into our content pipeline.

- **OpenAI launches GPT-5.6 family (Sol/Terra/Luna) to limited partners.** [OpenAI News](https://openai.com/news/) / [CryptoBriefing](https://cryptobriefing.com/openai-releases-gpt-56-models-to-20-partners-public-launch-expected-by-july-2026/) — Sol (flagship reasoning/cybersecurity), Terra (lower-cost business tasks), and Luna (fast/cheap high-volume) are in preview with ~20 trusted partners ahead of a broader GA; Sol is also being served on Cerebras hardware at up to 750 tok/s. **Applicable to The Construct: maybe** — not an immediate swap-in, but Sol-on-Cerebras inference speed is worth watching for any latency-sensitive agent workflows.

- **Google ships Gemini 3.5 Flash and Gemini Omni video tooling.** [heygotrade — Google I/O 2026 recap](https://www.heygotrade.com/en/news/google-io-2026-gemini-deepmind-contextual-ai/) — Gemini 3.5 Flash targets coding/agentic workloads at ~4x the output-token throughput of other frontier models with a 1M context window; Gemini Omni now blends text/photo/video inputs into edited video output, including custom AI avatars. **Applicable to The Construct: yes** — Gemini Omni's blended video editing is a plausible alternative/complement to our current motion-deck generation pipeline and worth a hands-on eval.

- **Agent-architecture arxiv drops worth a skim:** [DALIA (declarative agentic-workflow layer)](https://github.com/VoltAgent/awesome-ai-agent-papers), [REprompt (requirements-engineering-guided multi-agent prompt optimization)](https://github.com/VoltAgent/awesome-ai-agent-papers), [SWE-Pruner (task-aware context pruning for coding agents)](https://github.com/VoltAgent/awesome-ai-agent-papers) — three papers this cycle target more deterministic agent task graphs, principled prompt optimization for multi-agent systems, and trimming irrelevant code context before it hits the model. **Applicable to The Construct: maybe** — SWE-Pruner's context-pruning approach could reduce token spend in our own agent workflows if the technique is reproducible outside a research harness.
