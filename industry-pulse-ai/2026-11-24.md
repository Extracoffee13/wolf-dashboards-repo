1. **Claude Ship (beta) — Anthropic, 2026-11-23**
   https://9to5mac.com/2026/11/23/anthropic-launches-new-claude-ship-feature-for-builders · https://www.digitaltrends.com/computing/anthropic-claude-ship-code-review/
   Three PR agents (Code Review is GA; PR Steward and Claude Approvals are beta) that review, auto-fix and route approvals, started with `/ship` in Claude Code.
   **Applicable to The Construct: yes.** It could take over the Claude-agents "fan out and verify" step on repo PRs (wolf-dashboards, B9 site) before JEV/Gatekeeper approves. Keep Approvals human-gated.

2. **Claude Code "Code Mode" (experimental) — 2026-11-17**
   https://www.infoq.com/news/2026/11/claude-code-mode/ · https://www.marktechpost.com/2026/11/17/anthropic-claude-code-code-mode-javascript-tool-calls/
   Claude writes JavaScript to chain, parallelize and filter tool calls. It is off by default: set `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` and use v2.1.323 or later.
   **Applicable: maybe.** It could cut context and latency on bulk jobs such as alt-text sweeps, GSC index sweeps and site claims sweeps. Anthropic says it may change or be removed, so trial it on one routine first.

3. **Mistral Voxtral 3 audio family + Mistral Large 4 open weights**
   https://releasebot.io/updates/mistral
   Mistral released new open audio (voice) models and improved open weights for Large 4. The Large 4 date is Oct 29, from Wikipedia; the Voxtral 3 date is unconfirmed.
   **Applicable: maybe.** It is a self-hostable voice candidate for the B9 Studio / Vector voice box if per-call API cost becomes a problem.

4. **Graphon raises a $35M Series A for agent memory (RRE Ventures, ~2026-11-10)**
   https://letsdatascience.com/news/graphon-raises-35m-series-a-to-give-ai-agents-memory-aef58efb
   A memory layer for agents. Related: Plurai raised a $13M seed for agent simulation and testing on Nov 11 (https://unite.ai/plurai-raises-13m-seed-and-opens-ai-agent-simulation-platform).
   **Applicable: no (watch).** Our PRAXIS inbox and skills files already act as durable memory. Revisit if the Hermes agents start losing context between runs.
