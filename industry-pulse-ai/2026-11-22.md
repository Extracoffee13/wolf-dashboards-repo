- **Claude Code "Code Mode" plus v2.1.330 (Nov 20).** Code Mode (an experimental opt-in since 2.1.323 on Nov 12) has Claude write JavaScript that chains several tool calls in one step. 2.1.330 adds sign-in for Enterprise Admin Console orgs and lets Code Mode read images and PDFs. Sources: https://dataconomy.com/2026/11/19/anthropic-adds-code-mode-to-claude-code-for-chained/ · https://code.claude.com/docs/en/changelog
  **Applicable to The Construct: yes.** Multi-step Claude-agent fan-outs (bulk page audits, GSC sweeps, alt-text passes) could become one scripted step instead of dozens of round-trips, which cuts tokens and latency. Pilot it on one bulk B9 audit before using it more widely.

- **Anthropic self-hosted Managed Agents, plus the Fable 5.2 model and Claude Meetings, Whiteboards and Sheets (Nov 9–12).** Teams can now run the Managed Agents service and keep agent data on their own infrastructure. Claude Meetings joins video calls and turns the discussion into plans and tasks (beta for Team and Enterprise). Sources: https://www.anthropic.com/news/announcements · https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/
  **Applicable: maybe.** Self-hosted Managed Agents could run on the agent Mac or the render node as a managed alternative to the hand-built Hermes worker queue. Weigh the cost of migrating against the reliability of the current osascript dispatch. Meetings is only relevant if client calls (Lennar) move onto a Team plan.

Agent funding this month went to the infrastructure layer: Graphon raised $35M for agent memory (https://letsdatascience.com/news/graphon-raises-35m-series-a-to-give-ai-agents-memory-aef58efb) and Plurai raised $13M for agent simulation (https://unite.ai/plurai-raises-13m-seed-and-opens-ai-agent-simulation-platform).

- **Papers (not confirmed for this week; the most recent ones found were posted Jun–Oct 2026):** "Less Context, Better Agents" (https://arxiv.org/pdf/2606.10209; reports complete-itemization reliability rising from 8.0% to 91.6% through context engineering), "Memories That Outlive Their Reasons: Dependency-Tethered Memory" (https://arxiv.org/pdf/2610.25123), and "FlexA-Mem: Budget-Adaptive Agentic Memory" (https://arxiv.org/pdf/2610.33274).
  **Applicable: yes.** Our skills and memory sprawl is exactly the problem these papers address. Memory that records why it exists (and expires when that reason goes) maps directly onto pruning stale skills and Construct memory entries.
