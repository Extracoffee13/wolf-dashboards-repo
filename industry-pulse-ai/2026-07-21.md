# AI/Agent Ecosystem Pulse — 2026-07-21

- **[Anthropic release notes](https://code.claude.com/docs/en/changelog)** — Claude Code now runs subagents in the background by default (notifying on completion), Claude in Chrome went GA, and Claude's memory switched from daily summaries to individual categorized entries that update mid-conversation. **Applicable to The Construct: yes** — the background-subagent default and live memory entries directly affect how our Cowork sessions and scheduled routines (like this one) behave; worth re-checking any workflow that assumed synchronous subagent completion.

- **[Pipedrive native MCP server](https://www.pipedrive.com/en/newsroom/pipedrive-launches-native-mcp-server-bringing-crm-workflows-directly-into-ai-assistants)** — Pipedrive shipped a native MCP server letting AI assistants search deals, update contacts, schedule activities, and automate pipeline workflows in natural language. **Applicable to The Construct: maybe** — if any client (e.g. Brand 9 Signs or Prism/Pulse accounts) runs Pipedrive, this could replace bespoke CRM integration scripts with a direct MCP connector.

- **[Revid.ai MCP server + CLI](https://martechseries.com/video/leading-ai-video-generation-platform-revid-ai-launches-mcp-server-and-command-line-tool-giving-ai-agents-direct-access-to-video-production/)** — Revid.ai launched an MCP server exposing render_video, export_video, clone_voice, and schedule_publish/publish_now tools for agent-driven video production. **Applicable to The Construct: maybe** — a lighter-weight alternative/complement to the Higgsfield video pipeline already wired into Cowork; worth a side-by-side eval for turnaround time and cost on signage/social video jobs.

- **Frontier model churn** — [OpenAI shipped GPT-5.5](https://llm-stats.com/ai-news) with gains in agentic coding and computer use (Terminal-Bench 2.0: 82.7%), followed by GPT-5.6 Luna/Terra/Sol; [xAI released Grok 4.5](https://llm-stats.com/ai-news); [DeepSeek released V4-Pro/V4-Flash](https://llm-stats.com/ai-news) with 1M-token context tuned for long agentic runs. **Applicable to The Construct: no** — none of our agents are currently OpenAI/xAI/DeepSeek-backed, but the 1M-context DeepSeek release is worth flagging if any future long-document workflow needs a non-Anthropic fallback.

- **[Perplexity SPACE Sandbox + Claude Fable 5 orchestration](https://www.stanventures.com/news/state-of-perplexity-ai-july-2026-7441/)** — Perplexity added a sandboxed agent execution environment, self-improving memory, and multi-model orchestration (including Claude Fable 5 and mid-task model switching) to its Comet/Computer product. **Applicable to The Construct: no** — competitive signal only; no direct integration path today, but their "self-improving memory" framing parallels our own self-improving-loop skill and is worth watching for design ideas.

## Durable observation
Agent-platform vendors are converging on the same two primitives Anthropic shipped this cycle — background/async subagents and persistent per-entry memory — suggesting these are becoming table-stakes architecture, not Anthropic-specific features. MCP server proliferation is shifting from generic API wrappers toward vertical, workflow-specific tool sets (CRM pipeline actions, not just CRUD; video render/export/schedule, not just generate).
