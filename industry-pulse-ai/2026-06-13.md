**2. Claude Code June 2026: nested sub-agents, `/usage` breakdown, MCP safe-mode**
Source: [Releasebot](https://releasebot.io/updates/anthropic/claude-code) | [jangwook.net](https://jangwook.net/en/blog/en/claude-code-june-2026-new-features-changelog-developer-guide/)

**Applicable to The Construct: yes** — nested sub-agents are directly usable for multi-step campaign pipelines (research → copy → layout → proof); `/usage` helps audit which MCP tools are burning tokens in automated workflows.

**3. MCP ecosystem crosses 14,000 servers; OpenAI Realtime API adds MCP + SIP voice calling**
Source: [mcpmarket.com](https://mcpmarket.com/daily/top-mcp-server-list-may-25-2026) | [OpenAI](https://openai.com/index/introducing-gpt-realtime/)
The MCP SDK has exceeded 97M cumulative downloads. OpenAI's Realtime API now supports remote MCP servers, image inputs, and SIP-based phone calling, making voice agents tool-capable and phone-dialable natively.
**Applicable to The Construct: maybe** — SIP voice agents could handle inbound client intake or scheduling callbacks; the widening MCP server catalog (DAM, CRM, scheduling) is worth a quarterly audit against current workflow gaps.

**4. "Context Engineering" paper reframes agent prompting as a systems discipline (arxiv 2603.09619)**
Source: [arxiv](https://arxiv.org/abs/2603.09619v1)
Proposes context engineering (CE) as the practice of designing the full informational environment an agent operates in — not just the prompt. Five quality criteria: relevance, sufficiency, isolation, economy, provenance. Argues CE is to agentic AI what OS design is to software.
**Applicable to The Construct: yes** — the isolation and provenance criteria are immediately actionable when structuring system prompts for multi-agent content workflows; helps avoid context bleed across client projects in shared agent sessions.
