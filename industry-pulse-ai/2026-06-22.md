## 5. arxiv: "Agentic Software: How AI Agents Are Restructuring the Software Paradigm"
**Source:** https://arxiv.org/pdf/2606.05608 (June 11, 2026)

This paper argues that AI agents represent a fundamental restructuring of software where LLMs serve as the primary reasoning engine and decision logic is generated at runtime rather than statically coded — and that most legacy software architectures are ill-suited to orchestrate agents effectively.

**Applicable to The Construct: YES** — direct architectural input for how The Construct's agent orchestration layer should be designed; the core thesis (runtime decision logic vs. static code) should inform whether The Construct uses hardcoded workflow graphs or dynamic agent planning for its production pipelines.
