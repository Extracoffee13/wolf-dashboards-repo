- **Claude Code 2.1.259 ships `managedMcpServers` + `--permission-prompts none`**
  https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
  Organizations can now push HTTP/SSE MCP servers down as a managed setting, and headless hosts
  can run fully unattended with permission prompts disabled.
  **Applicable to The Construct: yes** — this is the missing piece for the scheduled routines
  (pre-market, congressional watch, consulting pulse, post-close). Today each headless run risks
  stalling on a permission prompt; `--permission-prompts none` removes that failure mode, and
  `managedMcpServers` lets us define the Construct's MCP set once centrally instead of per-agent.

- **Claude Fable 5.1 GA (2026-09-01), already the default Fable model in Claude Code 2.1.257**
  https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
  New generally-available model targeted at long-running agents, multistep research, and
  document-heavy work; same release added subagent model forcing and per-subagent effort control.
  **Applicable to The Construct: yes** — subagent model forcing maps directly onto the WOLF
  Committee's four-role split: cheap models for the Generalist/Operator scans, high-effort for
  the Quant and Skeptic passes, instead of running every role at one tier.

- **Frontier cadence stays weekly: Gemini 3.8 Flash and Qwen3.8-Max-0902 both landed 2026-09-02**
  https://llm-stats.com/llm-updates
  Two flagship-tier releases in a single day; no OpenAI, Meta, Mistral, xAI, DeepSeek, or Cohere
  release in the window (last majors: GPT-5.6 Sol GA 2026-07-09, Grok 4.6 2026-08-12).
  **Applicable to The Construct: maybe** — Flash-tier models are the right economics for the
  high-volume, low-judgment legs (filing scrapes, arxiv triage, link dedup), but nothing here
  justifies moving the Committee's reasoning off Claude. Revisit only if latency on the 09:00 ET
  pre-market run becomes the binding constraint.

- **arxiv 2609.00237 — "Learning What to Retain: Gated-Memory Routing for Efficient Collaboration
  in Multi-Agent LLM Systems"** (EMNLP 2026)
  https://arxiv.org/abs/2609.00237
  Proposes a learned Memory Write Gate that commits only non-redundant reasoning steps and a
  Retrieval Gate that hands each agent a compact relevant subset, rather than routing on the query
  alone or on full execution history.
  **Applicable to The Construct: yes** — this is a formal version of what PRAXIS_INBOX is doing by
  hand. The write-gate framing argues our packets should be filtered on non-redundancy against
  prior lessons before they are committed, not appended unconditionally; the retrieval gate argues
  each agent should be handed its own slice of the inbox rather than the whole file.
