### 5. arxiv: "Context Engineering" as a Formal Discipline (2603.09619) + Agent Governance LGA Framework
**Source:** [arxiv 2603.09619 — Context Engineering](https://arxiv.org/abs/2603.09619) | [arxiv 2603.07191 — Governance Architecture for Autonomous Agent Systems](https://arxiv.org/abs/2603.07191v2)

Vera Vishnyakova's *Context Engineering: From Prompts to Corporate Multi-Agent Architecture* formalizes CE as a discipline for designing the full informational environment in which agents make decisions — moving well past single-prompt thinking. A companion paper proposes the **Layered Governance Architecture (LGA)**: four layers covering execution sandboxing, intent verification, zero-trust inter-agent auth, and immutable audit logging to address prompt injection, retrieval poisoning, and uncontrolled tool invocation.

**Applicable to The Construct: YES** — Context Engineering reframes how Construct agent prompts should be architected at scale. LGA is a direct reference model for hardening the PRAXIS multi-agent mesh before client-facing deployments.
