# AI / Agent Ecosystem Pulse — 2026-11-15

Scope: Anthropic, frontier labs, MCP registries/press, agent-platform funding, arXiv.
Note: the strict last-24h window (Sat → Sun) was quiet; items below are the most recent dated items from the past ~7 days. Several dates come from secondary trackers and should be checked against the primary source.

- **Anthropic ships Claude Meetings, Whiteboards, Sheets (beta) and Claude Data (GA)** — Nov 10. Claude can join video calls and produce plans, whiteboards and tasks while the conversation is still going; Data turns on by default for Enterprise around Nov 19–20 (sources disagree on the date).
  Sources: https://www.unite.ai/anthropic-launches-claude-whiteboards-and-sheets-in-beta/ · https://note.com/startup_now0708/n/n890ac57702f8
  **Applicable to The Construct: yes.** Meetings could replace the manual step of turning client calls (Lennar decks, B9 bids) into notes and then tasks: it writes the plan and task list while the call runs, and those can go straight into a PRAXIS_INBOX block or a Hermes dispatch. It's Team/Enterprise beta only, so check our plan tier first.

- **Claude Fable 5.2 and Mythos 5.2 released** — Nov 9. Anthropic's top models for heavy technical work. Fable 5.2 costs $8 / $40 per million input / output tokens and runs up to 30% faster than 5.1; fast mode costs $16 / $80.
  Source: https://www.anthropic.com/news/announcements
  **Applicable: maybe.** It's a cheap swap for the long multi-step jobs (VironBox builds, Vector design gate). Benchmark one real job against our current model before switching the defaults, because the price per token is high.

- **Wave of enterprise MCP servers, now with actions, not just reads** — Charles Schwab launched an MCP server pilot on Claude that can take actions as well as read data (Nov 12–13).   Source: https://riabiz.com/a/2026/11/13/schwab-surprises-analysts-with-extra-rapid-launch-of-own-mcp-servers-also-leaping-from-read-only-to-agentic-get-stuff-done-ai-it-leaves-rias-out-for-now-and-makes-anthropics-days-numbered-as-schwabs-exclusive-llm

- **arXiv audit: "~72% of an agent's named cognitive modules are decoration"** — reported Nov 11. An ablation audit of a well-known LLM agent found that most of its named modules (theory of mind, global workspace and so on) barely change what the agent does.
  Source: https://aitoolly.com/ai-news/article/2026-11-11-your-ai-agents-brain-is-72-decoration-insights-from-a-recent-arxiv-audit (secondhand; original paper not yet located)
  **Applicable: yes.** The Construct has more than 150 skills and about 19 named agents. Run an ablation pass: turn skills or agents off one at a time on real tasks and retire the ones that change nothing. This is the "gates over documents" rule applied to the agent roster.
