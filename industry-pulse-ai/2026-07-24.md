# Industry Pulse — AI/Agent Ecosystem — 2026-07-24

- **MCP spec's biggest rewrite ships July 28** — [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) / [The Register](https://www.theregister.com/devops/2026/07/23/model-context-protocol-prepares-to-break-with-its-stateful-past/5276722): the 2026-07-28 spec drops sessions and the init handshake, moves long-running work into a "Tasks" extension, adds server-rendered UI via "MCP Apps," and rewrites auth to align with OAuth/OIDC — a remote server can now run stateless behind a plain load balancer instead of needing sticky sessions. **Applicable to The Construct: yes** — every custom MCP server we build (Higgsfield, Slack, GitHub tooling) should target the new stateless/auth model before the 10-week compatibility window closes; worth a compatibility pass on our own tooling.

- **Anthropic ships "Record a Skill" in Cowork (July 21)** — [Cowork plugins blog](https://claude.com/blog/cowork-plugins) / [explainx.ai](https://explainx.ai/blog/claude-cowork-record-a-skill-screen-recording-july-2026): screen-record a task once and Cowork turns it into a reusable, rerunnable skill — no manual prompt authoring. **Applicable to The Construct: yes** — this could replace some of our manual skill-authoring for repetitive Bobby workflows (WordPress publishing, LinkedIn posting) by having him record the click-path once instead of us hand-writing skill docs.

- **Revid.ai launches MCP server + CLI for full video pipeline (July 16)** — [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/leading-ai-video-generation-platform-183300269.html): exposes `render_video`, `clone_voice`, `schedule_publish`, `publish_now` etc. as agent-callable tools, letting an agent run script→render→publish end-to-end. **Applicable to The Construct: maybe** — a second video-gen backend alongside Higgsfield; worth a bake-off only if Higgsfield hits a capability gap (e.g., scheduled multi-platform publish).

- **Watchfire adds AI content generator to Ignite OPx digital signage platform** — [MarTech roundup](https://martech.org/the-latest-ai-powered-martech-news-and-releases/): generative image/text models create background graphics and display copy from plain-language prompts directly inside a signage management platform. **Applicable to The Construct: yes — directly relevant to Brand 9 Signs.** A signage-industry competitor/adjacent platform is now baking generative content into the CMS layer; worth watching as a signal for what signage clients will expect as table stakes.

- **Frontier model wave continues**: Google shipped **Gemini 3.6 Flash** (July 21); Moonshot AI announced **Kimi K3** (2.8T params, 1M context, open weights July 27); OpenAI shipped **GPT-5.6** (Sol/Terra/Luna variants); xAI shipped **Grok 4.5**. [ThursdAI roundup](https://thursdai.news/releases/2026-07). **Applicable to The Construct: maybe** — no immediate action, but Kimi K3's open weights + 1M context is worth a cost/quality benchmark if we ever need a cheaper long-context fallback model outside the Claude stack.
