# Industry Pulse — AI/Agent Ecosystem — 2026-09-23

- **[Claude Code beta: project-level coordination](https://releasebot.io/updates/anthropic/claude-code)** — Claude Code now defaults to Opus 5.5 and ships a beta "Projects" experience letting one project coordinate parallel threads, shared memory, and a project library across long-running work. **Applicable to The Construct: yes** — this overlaps directly with our Praxis/Hermes swarm coordination pattern (shared inbox, multi-agent memory); worth evaluating whether native Claude Code Projects can replace or simplify parts of our hand-rolled praxis-inbox mechanism.

- **[Screenly ships production MCP server for digital signage](https://cast-hub.com/digital-signage-mcp-vendors/)** — Screenly's CLI now bundles a 33-tool MCP server (API-token auth) letting AI assistants schedule promotions and content across multi-location signage networks. **Applicable to The Construct: yes** — directly in Brand 9 Signs' industry; worth a scoping call on whether B9 clients on Screenly (or similar CMS) could get an MCP-driven scheduling assist, and whether we should track/benchmark against it for our own signage-adjacent tooling.

- **[OpenAI ships GPT-6 Luna/Sol; xAI ships Grok 4.7](https://llmgateway.io/timeline)** — OpenAI released two new GPT-6 variants (Luna, Sol) on Sept 22 and xAI shipped Grok 4.7 on Sept 21, continuing the weekly frontier-model release cadence (20 new models from 12 providers so far this month). **Applicable to The Construct: maybe** — no immediate action, but worth a quick capability/cost check against Opus 5.5 for any workload where we're currently over-provisioned on model tier.

- **[Glean raises $150M Series F at $7.2B for enterprise agent platform](https://www.glean.com/press/glean-raises-150m-series-f-at-7-2b-valuation-to-accelerate-enterprise-ai-agent-innovation-globally)** — Glean's new round funds expansion of its enterprise AI agent platform (search + multi-step task execution) globally. **Applicable to The Construct: no** — enterprise search/agent platform doesn't map to our current stack; noting only as a market signal that agent-platform valuations continue to climb.

- **["Context Engineering: From Prompts to Corporate Multi-Agent Architecture" (arXiv:2603.09619)](https://arxiv.org/abs/2603.09619)** — proposes five context-quality criteria (relevance, sufficiency, isolation, economy, provenance) and frames context as the agent's operating system, plus "intent engineering" for encoding org goals/trade-offs into agent infra. **Applicable to The Construct: yes — how** — the five criteria are a clean checklist for auditing our own agent prompts/skills (e.g. skill bloat, memory isolation between Hermes agents); could inform a pass on trimming or restructuring our largest skill files.
