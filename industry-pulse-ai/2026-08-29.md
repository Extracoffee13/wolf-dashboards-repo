# Industry Pulse — AI/Agent Ecosystem — 2026-08-29

- **Anthropic ships Claude for Teachers + Claude Team plan for Scientists** — [Anthropic Newsroom](https://www.anthropic.com/news) / [explainx.ai recap](https://www.explainx.ai/blog/claude-team-plan-for-scientists-10000-seats-august-2026). Claude for Teachers rolled out to U.S. K-12 schools/districts, and a new Claude Team plan gives 10,000 scientists free standard seats (premium seats at 5x limits, $15/mo, 80% discount locked one year). **Applicable to The Construct: no** — vertical/education and research-lab seat deals, not a workflow or tooling change we'd adopt.

- **Claude Code / Claude platform widen MCP 2026-07-28 spec support** — [Releasebot: Anthropic release notes](https://releasebot.io/updates/anthropic). New stateless MCP core, stronger OAuth/OIDC authorization, versioned Apps/Tasks extensions, plus Claude Code adds restricted mode, cross-session messaging, and better server-managed settings diagnostics. **Applicable to The Construct: yes** — cross-session messaging and the stateless MCP core are directly relevant to how our Hermes/Cowork agent mesh talks to MCP servers (Slack, GitHub, Higgsfield); worth testing restricted mode for any agent with write access to client-facing systems.

- **Perplexity's "Computer" agent hits $750M ARR, adds Deep Research + expanded model routing** — [Sacra: Perplexity revenue/valuation](https://sacra.com/c/perplexity/) / [Releasebot: Perplexity](https://releasebot.io/updates/perplexity-ai). Computer now turns a research question directly into a report, spreadsheet, deck, dashboard, or website in one flow, and routes across GPT-5.6, Grok 4.6, DeepSeek V4 Pro, Kimi K3, Nemotron 3.5. **Applicable to The Construct: maybe** — the "one prompt → deliverable format" agent pattern is close to what several of our Operators (Pulse, Keystone) already do; worth a competitive glance but not a tool swap.

- **xAI/Starlink scale Grok Voice to production support+sales load** — [aitoolsrecap.com: AI News Aug 28 2026](https://aitoolsrecap.com/Blog/AINewsAugust2026.aspx). Grok Voice (Think Fast 2.0, default since Aug 5) is now handling 15,000+ inbound support/sales calls/day and 3,000+ orders/week for Starlink. **Applicable to The Construct: no** — telecom-scale voice support isn't in our client mix, but it's a proof point for voice-agent reliability at volume if a future client needs it.

- **arXiv: "Context Engineering" formalized as a discipline distinct from prompt engineering** — [arxiv.org/abs/2603.09619](https://arxiv.org/abs/2603.09619). Proposes five context-quality criteria (relevance, sufficiency, isolation, economy, provenance) for multi-agent systems, drawing on Google ADK/Anthropic/LangChain architectures. **Applicable to The Construct: yes** — directly usable checklist for auditing our own skill/memory files (SKILL.md corpora, praxis-inbox, brand-voice docs) for bloat and provenance gaps.
