- **Anthropic — Claude Platform on AWS + Managed Agents with private MCP support**
  Source: https://releasebot.io/updates/anthropic
  Anthropic launched Claude Platform on AWS (full Messages/Files/Batches API via AWS billing and IAM) alongside Managed Agents that can now run inside a customer-controlled sandbox and connect to private MCP servers.
  **Applicable to The Construct: YES** — private MCP wiring means WOLF/PRAXIS agents could connect directly to The Construct's CRM, DAM, and signage scheduling systems without exposing data to public endpoints.

- **MCP Spec 2026-07-28 RC: stateless HTTP core + MCP Apps (server-rendered UIs) + Tasks extension**
  Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
  The largest MCP revision since launch drops stateful session requirements (plain round-robin load balancers now work), adds server-rendered UI surfaces via MCP Apps, and formalizes long-running work via a Tasks extension; 10,000+ servers now indexed in the public registry.
  **Applicable to The Construct: YES** — MCP Apps could deliver lightweight scheduling/approval UIs inside agent workflows; the Tasks extension directly solves long-running signage render jobs that currently require manual polling.

- **DeepSeek V4 Pro — MIT license, 75% price cut vs. prior frontier tier**

  **Applicable to The Construct: MAYBE** — could replace mid-tier Claude calls in high-volume batch workflows (content tagging, asset description) to cut costs, but requires self-hosting or third-party API for MIT use.

- **Cognition raises $1B Series D at $25B valuation (Devin autonomous coding agent)**

- **"Context Engineering" — arXiv 2603.09619 (June 2026)**
  Source: https://arxiv.org/abs/2603.09619v1
  Proposes retiring "prompt engineering" in favor of "context engineering" — treating context as the agent's operating system and evaluating it against five criteria: relevance, sufficiency, isolation, economy, and provenance.
  **Applicable to The Construct: YES** — directly applicable to refactoring PRAXIS/WOLF agent system prompts; the isolation and economy criteria in particular address the context bloat observed in current inbox-processing routines.
