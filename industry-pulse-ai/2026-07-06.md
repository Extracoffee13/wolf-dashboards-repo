# Industry Pulse: AI/Agent Ecosystem — 2026-07-06

- **Claude Sonnet 5 is now live and the Claude Code default** — Anthropic's most agentic model yet ships with a native 1M-token context window and promo pricing ($2/$10 per Mtok through Aug 31); Anthropic also shipped a Claude apps gateway for Bedrock/Google Cloud (SSO, RBAC, spend caps) and richer Enterprise admin analytics. [Anthropic Newsroom](https://www.anthropic.com/news) | [Releasebot — Claude Code](https://releasebot.io/updates/anthropic/claude-code)
  **Applicable to The Construct: yes** — worth trialing Sonnet 5 as the default model for wolf-dashboards agent work now that it's the Claude Code default; the 1M context window could remove the need for some of our current context-chunking workarounds.

- **Digital signage CMS platforms are shipping native MCP servers** — as of late May 2026, CastHub, Screenly, and Revel Digital have production-grade MCP servers; Fugo and NoviSign are in beta; Korbyt has a public roadmap. Separately, Aprimo ("Agentic DAM"), Cloudinary, Frontify, and Adobe now ship native MCP servers for asset management. [CastHub — Digital Signage MCP Vendor Guide](https://cast-hub.com/digital-signage-mcp-vendors/)
  **Applicable to The Construct: yes** — directly on-thesis for WOLF/signage dashboards; an MCP integration with CastHub or Screenly could let our agents push/pull signage content and status without custom API glue. Worth a spike.

- **Anthropic shipped 17 official Claude Code skills and 11 Cowork plugins** for knowledge-work roles (sales, legal, finance, data analysis), bundling skills + connectors + slash commands + sub-agents into role-specific packs. [Anthropic — Cowork Plugins](https://claude.com/blog/cowork-plugins) | [Medium recap](https://medium.com/@reactjsbd/anthropic-ships-17-skills-for-code-and-11-plugins-for-cowork-c752d2ae5a20)
  **Applicable to The Construct: maybe** — none of the 11 packs map directly to signage/media ops, but the plugin pattern (bundle skill+connector+subagent) is a template we could copy for a Construct-specific plugin.

- **Frontier model activity is incremental, not a step-change** — xAI's Grok 4.3 landed on Amazon Bedrock ($1.25/$2.50 per Mtok, 131K context); Google shipped Gemini 3.1 Flash Lite Image (June 23). No major new frontier release from OpenAI, Meta, Mistral, or DeepSeek surfaced in the last 24h. [llm-stats.com — AI Updates](https://llm-stats.com/llm-updates)
  **Applicable to The Construct: no** — nothing actionable this cycle; keep monitoring Grok 4.3 pricing as a potential cheaper fallback model.

- **Agent-architecture research this week centers on "context engineering" as the layer above prompting** — arXiv 2603.09619 frames context (not prompts) as the agent's operating system, proposing relevance/sufficiency/isolation/economy/provenance as quality criteria for multi-agent systems; also notable: AgentSPEX (arXiv 2604.13346), a formal agent specification/execution language, and Tmax (arXiv 2606.23321), a simple recipe for terminal agents. [Context Engineering paper](https://arxiv.org/abs/2603.09619) | [AgentSPEX](https://arxiv.org/pdf/2604.13346) | [Tmax](https://arxiv.org/pdf/2606.23321)
  **Applicable to The Construct: yes** — the context-engineering quality criteria (relevance/sufficiency/isolation/economy/provenance) are a useful checklist to audit our praxis-inbox / wolf-brief context pipelines against.
